# 拾日

拾日是一款面向大学生的 Android 日程与任务管理 App，把课程、群通知、待办、考试和学习安排放在一起。

收到“明天9:15到A301开会”，可以把原消息或截图交给助手。系统结合课表检查时间，保留尚未说明的结束时间，给出可核对的预览。任务也能先记下来，等需要安排学习时间时再补充预计用时。

当前版本 **1.1.1，Android 构建号 12**。客户端使用 Flutter，后端使用 Python / FastAPI，正式数据库使用 PostgreSQL。文字助手调用 DeepSeek；OCR 和录音转写在服务端运行；学习排程使用 OR-Tools；标签归类和同类合并使用程序规则，无需调用大模型。

## 功能

| 内容 | 能做什么 |
| --- | --- |
| 今日 | 查看当天安排、下一项活动、待办、考试提醒、学习空档和忙闲情况，调整首页内容 |
| 日程 | 周课表和列表查看、切周与跳日期、手动新增、修改日程，展示完整或不完整时间 |
| 课程与学期 | 创建和切换学期、调整作息、导入或手动录入课程、按具体课次调课和记录请假 |
| 通知助手 | 文字、截图、录音输入，查询已有记录，多轮补充或纠错，核对预览、保存、查看回执和撤销 |
| 任务与学习 | 待办、作业、考试、批量操作、进度记录、学习时段、方案预览、固定计划和重新安排 |
| 标签 | 自动归类并合并同类名称；点标签看关联事项和日程，支持跨学期查看和继续打开详情 |
| 查找与统计 | 搜课程、日程、待办和来源文字；查看时间、分类、标签及进度统计 |
| Android 系统入口 | 本地提醒、离线延后、桌面日程卡、快速记录、系统分享、用户主动开启的进行中通知 |
| 账号与数据 | 注册、登录、恢复码、退出、个人资料、反馈问题、导出数据、删除来源附件和注销账号 |

所有用户功能的入口、规则和限制见[完整使用说明](docs/产品规则.md)，对应实现见[功能清单](docs/功能清单.md)。

## 安装

[下载 GitHub v1.1.1 发行版](https://github.com/Keleoz-Cyber/SemesterOS/releases/tag/v1.1.1)。发行版包含正式 APK、SHA-256 校验文件及构建信息。最低 Android 7.0（API 24），支持 armeabi-v7a、arm64-v8a、x86_64。Android 16 的增强通知需要系统允许，显示样式由系统和厂商决定。

## 从源码运行

准备 Python 3.12、Docker Desktop、Flutter（Dart 满足 `^3.12.2`）、Android SDK、JDK 21；学校页面脚本测试另需 Node.js。首次复制[配置示例](.env.example)为 `.env` 并填写数据库与模型配置，已有配置直接使用。

在仓库根目录的 PowerShell 启动后端：

```powershell
.\scripts\dev.ps1 -Action Api
```

另开窗口启动 App：

```powershell
.\scripts\dev.ps1 -Action Android -Device emulator-5554
```

开发模拟器使用 `http://10.0.2.2:8871`，正式 APK 使用 `https://semesteros.keleoz.com`。手机连接和环境设置见[移动端说明](apps/mobile/README.md)，完整部署和打包见[部署与维护](docs/部署与维护.md)。
