# 学期OS（SemesterOS）

面向大学生的学期事务管理 App：将课表、作业、考试和临时通知转为可追溯的事项，分析时间余量，生成个人计划，并在现实安排变化后进行最小扰动重排。

## 当前状态

已完成产品、技术、UI交互与测试设计，尚未开始产品代码开发。第一版面向 Android，支持多用户注册，iOS 后续适配。

技术设计采用 Flutter、FastAPI、PostgreSQL 与 OR-Tools；具体依赖版本将在建项时验证并锁定。AI负责解析和解释，规划模块负责约束校验，正式修改由用户确认。

## 下一开发阶段

建立 Flutter Android 工程与后端基础设施，验证真实教务登录及课表读取，再完成注册登录、学期初始化、导入确认和周课表展示。

Android 调试计划使用 Android Studio 模拟器与真机。模拟器上的结果不能替代真实教务会话和所需平台能力的验证。

## 数据与开发约定

- 教务密码、Cookie、模型密钥和签名密钥不进入仓库。
- 临时文件、设备配置和构建产物由 `.gitignore` 排除。
- 合成演示数据与真实试用数据分开；示例导入不视为真实认证导入成功。
- 保留来源、版本和确认记录；AI失败后基础事务仍应可管理。
