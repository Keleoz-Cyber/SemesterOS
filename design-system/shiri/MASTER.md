# 拾日设计系统

本文件记录当前 Flutter App 的设计与交互规则。产品面向大学生日常事务，Android 优先；四页为今日、日程、任务、学期，助手是统一的图片、语音与文字入口。源码实现优先于历史原型或阶段报告，不用组件数量表达完成度。

## 颜色、文字与布局

颜色对应 [campus_theme.dart](../../apps/mobile/lib/ui/campus_theme.dart)，共用控件与 Forui 主题分别见 [app_controls.dart](../../apps/mobile/lib/ui/app_controls.dart) 和 [forui_theme.dart](../../apps/mobile/lib/ui/forui_theme.dart)。

| 语义 | 色值 |
| --- | --- |
| 页面 / 内容面 | #F5F7FB / #FFFFFF |
| 主要操作 / 次级强调 | #3D66C1 / #34766F |
| 蓝色浅底 / 青绿浅底 | #EEF3FC / #EDF5F2 |
| 主文字 / 次文字 / 分隔 | #24344D / #5F6F84 / #E3E9F1 |

普通操作以蓝色为主，课程使用稳定的低饱和度分类色；警告和错误只表达对应状态。分类色不表示优先级，颜色不能是类型、风险或选中的唯一依据。现行亮色主题支持系统高对比度；没有完成全 App 暗色与无障碍认证。

中文跟随系统无衬线，时间数字支持等宽。正文以 16sp、辅助 14sp 为起点，保留系统字号；4/8dp 间距、16/20dp 页面边距按内容调整。长名称、日期组与动作放不下时换行或纵排，避免孤字、强制省略和层层圆角外框。系统安全区、键盘和底部动作是布局约束。

关键操作目标至少 48dp，提供明确语义、焦点与键盘激活。密集七列课表另提供完整日程列表和大日期目标，不将所有网格单元宣称为 48dp。拖动排序、图表点选等保留可发现的按钮或文字替代。

## 页面与操作层级

- 今日默认同屏展示今日日程与待办，今日状态在前、明天预览在后。完整日程 / 待办视图在首页设置中选择，保留旧偏好；每节“查看全部”进入对应完整列表。模式里未展示的模块不提供无效设置；模块设置只影响本机展示，不改变事项时间、优先级或服务端计划。
- 日程提供周课表与列表，记住用户视图选择；点日期进入单日，切换保留周表滚动位置。日期范围紧凑显示、当前周与所选日明确，助手收在工具栏。未知结束是时点，截止、仅日期和未定记录独立呈现。
- 课程以真实钟点、名称和已有地点组成连续账本。同一课程多组安排先选择具体组，再编辑；导入变化突出旧 / 新差异，旧教务课程默认保留，手工修改与免听状态不得被外观调整覆盖。
- 任务页联系待办与已安排时段，直接新建任务与整理通知分别可达。列表只放标题、截止 / 剩余和必要风险结论；可见完成入口复用计划影响确认及撤销流程。剩余量、已安排量与实际投入分别呈现，未知值不补成零或完成百分比。
- 学习时段设置属于“学习安排”标题行，空列表也可设置；“全部安排”在已有安排或待安排任务时提供，不另放一个游离的学习时间按钮。批量设置可选择多个星期、多个任意钟点范围，保存后每周重复；默认合并已有时段，替换需明确选择。账号内记住上次批量组合，应用先更新草稿，最终保存仍核对实际变化。
- 学期使用可滚动周次刻度，当前周与选中周分开。选中面随操作移动，快速点选落在最后选择；课程、考试、统计、标签和管理为次级入口。
- 统计注明范围与口径，课程、固定安排、个人计划和实际用时分别计算；分类 / 日期筛选连接具体记录。没有实际投入记录不推测效率、完成率或趋势。
- 详情先显示名称、已有时间 / 地点和通知要求，编辑在顶栏，低频动作在菜单；提醒条目直接编辑该条。空教师、地点、结束、耗时和来源不占位；缺项仅在当前操作依赖它时说明。

一个提交或编辑场景突出一个主要动作；导航、查看和就地操作采用轻量文字 / 图标，不自动套常驻外框。提交等待防止重复请求，打开菜单与页面不制造等待；弹窗下面、隐藏页面和后台不持续播放忙碌动画。保存后使用真实回执，失败在原位置给原因与重试，保留草稿。

页面 / 模式切换不用勾选表达；单字段值使用可取消的选择窗口，长列表可搜索；勾选用于真实多选。开关与所属字段放在一起，数值操作立即生效于草稿，最终保存仍由原业务流程确认。取消不修改记录。

## 统一助手与来源

语音和键盘共用输入区：用户按住录音、松开完成、上滑取消，打开页面不启动麦克风；后台停止采集。图片上传、识别、重试和结果留在本轮对话，识别文字可编辑，不再增加第二套录入流程。

通知中的人物、来源时间与本人身份分别处理；资料是选填自述，不能变成权限或模型指令。分享、粘贴和转发文案不自动发送或保存，学生自行修改的文本不被迟到结果覆盖。来源归属本条消息，原文、图片、录音与补充要求可查看。

查询、候选、修改、分组冲突、确认、回执和撤销用真实结构化结果区分。避免工具字段、内部思维过程、虚构百分比、预计用时和重复宣传说明。当前对话与历史按需加载；历史回执不重复播放成功动画，编辑问题不隐式撤销已保存业务。

普通“哪天有一小时空闲”按已记录日程查询，默认每天 08:00—22:00，卡片明确范围；用户指定全天、跨午夜或其他钟点时采用指定范围。只有明确查询学习时段内的空闲才使用学习偏好，查询不改设置。普通空闲查询按完整结构化结果生成日期摘要，具体时段放卡片，查询依据收进“更多说明”；用户明确要求详细分析则保留完整回复。无结果只解释一次，未知结束不补造结束时间；可能有空但需核对的时段明确标注，不说成确定空闲或整个后续日期都没空。

同时明确更正剩余量并排程时，一份预览同时展示原剩余量、新值和时间块，一次确认保存，联合撤销保留依赖校验。单次分钟数与总目标分开，自定义天数及短时段不被固定选项替代。连续时段放不下时明确是在已保存学习偏好内放不下，不声称全天没有空闲；剩余量和时间块未保存时如实说明。

从日程页打开助手时，输入区显示可移除的浏览日期范围。范围是本轮页面上下文，仅辅助“那天、这一天、这一周”等指代；今天、明天与来源通知日期保持原义。媒体、重试、编辑与历史保留可见范围，不从历史请求静默继承为当前选择。

资料培养层次仅本科 / 研究生，空资料两者不选，已选项可取消；其他资料也不使用占位选项冒充事实。提醒默认遵循用户设置，课前提醒默认关闭；只有用户开启或实际依赖权限时引导。

## 时间与范围输入

当前时刻选择使用小时、分钟竖向滚轮，保留 00—59 任意分钟；不把学校 08:37 等值吸附为整刻。窗口仅保留必要端点、标签和确认，底部确认固定可见，内容可滚动。当前没有额外键盘时间模式、横向刻度或固定 15 分钟快捷栏。

| 场景 | 时间边界 |
| --- | --- |
| 学期节次 | 同窗编辑开始 / 结束，当天结束晚于开始，不写入 24:00 或跨午夜节次 |
| 每周学习时段与任务安排候选 | 同窗编辑两端，结束可选当天 24:00 |
| 临时不可用、固定活动、调课与操作窗口 | 同窗核对两端日期和时刻，明确日期后可跨日 |
| 事项、考试、提醒与原消息时间 | 保留仅日期、范围、周次、候选和未知结束等原精度，不补造截止或占用 |

学校日期与钟点明确按 UTC+08:00 转换，不受设备时区或夏令时影响。预计耗时、实际投入和剩余工作量属于分钟时长，使用时长输入，不混成钟点。校历首周日期保留周一约束。

关闭或返回只丢弃选择器草稿；“应用时间”写回页面草稿，最终业务保存沿原入口执行。起止合法性、来源精度、实际影响和版本冲突都保留，不因精简布局收紧合法时间表达。

时间轨道压缩空档；当前时刻文字与标记同行。只有真实起止已知的进行中条目绘制进度；空档在相邻事项间定位，全天已结束时放在最后，空列表和非当天不放悬空时刻。

周课表的现在标记放在左侧时间轴留白：细竖轨表示已过时段，圆点定位当前时刻，表头显示“现在”和钟点。标记不穿过课程列，不遮挡名称与地点；非当前周不显示，仍遵循真实钟点与压缩空档映射。

## 动效与验证

反馈约 120ms、页面与选中约 220ms、抽屉约 300ms、图表约 350ms；这些是设计起点，按交互调节。动效表达真实操作，能被新输入打断；减少动画直接到终态，隐藏和后台停止计时。切页保留状态，隐藏页、关闭区域与已冻结提交不接收焦点。文字回复流式追加不重复淡入整段；日程切换只绘制当前内容，避免两页文字重叠。

逐区域检查普通手机、320dp 大字、横屏、键盘、展开、长文、空、加载和失败状态，查看实际生产 Widget 与原生截图；功能检查验证合法输入、取消 / 返回、具体写入对象、账号隔离及旧请求失效。测试通过不替代视觉审阅，组件图不替代真实设备、模型和校方登录。
