## 1. 现状诊断：为什么"单调、死板"

逐页看过 0.1.0+7 的真机截图（`output/feedback-20261007`、`output/suggestions-complete-20261007`），问题集中在下面 6 点。

1. **只有一层灰白面**。全局背景 #F5F7FB，内容几乎都是平铺的文字行。层级只靠字号和粗细，没有前后关系，看起来像一张表格。
2. **所有条目长一个样**。今日日程、待办、周列表都是"时间 + 标题 + 箭头"。"正在进行""下一节""已结束"在视觉上没有区别，最重要的那一项不突出。
3. **品牌和界面脱节**。新图标是天蓝、青、薄荷的渐变加金色太阳；界面还是旧的深蓝 #3D66C1 加墨绿 #34766F。
4. **底部太重**。每个主页面都有一整条输入栏，下面再叠一条导航栏，两层实心横条压在底部。
5. **动效只有淡入淡出**。点了之后东西"出现"了，但不知道它从哪来、到哪去：没有空间连续性，没有手势反馈，也没有一个让人想再点一次的时刻（任务完成的动效除外）。
6. **空状态敷衍**。"今天没有安排"配的是一张上升折线图，含义对不上；图标全是默认 Material 线性图标，没有类别辨识度。

## 2. 设计方向：「晴日」

新图标就是视觉语言的来源：
- 白色通透的玻璃底板；
- 天蓝 → 青 → 薄荷的渐变笔画；
- 一轮升起的金色太阳；
- 底部两层柔和的波浪；
- 左上角一道高光。

关键词：**通透、有日光、轻盈、有秩序、灵动**。

### 三条全局规则（每个页面都按这三条自检）
1. **亮度来自内容，色彩有节制**。底色接近白，色彩集中在课程色块、品牌渐变的进度和指示上。金色只用于"今天 / 现在 / 太阳"，用量很少。
2. **一屏一个主角**。每屏只有一个最强的视觉焦点（今日是"下一节"，日程是"今天这一列"，任务是"今天截止"），其他内容逐级退后。每个场景只放一个主按钮。
3. **动效表达真实因果**。东西从哪里来、到哪里去要看得出来：容器变换、弹簧指示块、填充。不做无意义的装饰动画，也不做常驻循环；骨架屏闪光和"按住说话"的波形除外。

### 不要做
- 励志句、口号、情绪化的关怀文案、虚构的百分比或评分（MASTER 规则）。
- 把品牌渐变铺在小字背后，或给每一行都加阴影和外框。
- 儿童化的字体或卡通人物，表情符号当图标。
- 常驻漂移的波浪、一直闪的点、自动轮播。

## 4. 字体

- 用系统字体（Android 上是 Roboto + Noto Sans CJK）。**所有数字一律用等宽数字**（`FontFeature.tabularFigures()`），倒计时、时刻在变化时不会抖动。
- 字号阶梯（字号/行高 字重）：

| 名称 | 规格 | 用途 |
|---|---|---|
| display | 34/40 w700 −0.6 | 今日日期 |
| headline | 26/32 w700 | 页面标题（第10周、任务） |
| title | 20/26 w600 | 卡片标题、详情标题 |
| titleSmall | 17/24 w600 | 列表标题 |
| body / bodyStrong | 16/24 w400 / w600 | 正文（不低于 16） |
| bodySmall | 14/20 | 次要信息 |
| label / caption | 13/18 w600、12/16 w500 | 芯片、徽标、时间刻度 |
| numXL / numL / numM / numS | 44 / 28 / 17 / 13，等宽 | D-6 倒计时、14:00、列表时刻、小时刻 |

- 文字放大到 1.6 倍时：换行或纵向排列，不强制省略。分段控件和芯片允许换行，最小高度保持 48。

## 5. 间距、圆角、阴影、材质

- **间距**：基于 4。页面左右 20（窄于 360dp 时 16）；卡片内边距 16–20；卡片之间 12；区块之间 28。
- **圆角**：芯片 8–9、输入与小卡 12、卡片 16–20、页头卡与弹层顶部 28、胶囊与导航坞 26–28。图标底板用 22% 的比例圆角，和 App 图标一致。
- **阴影**：
  - card：0 1 2 /4% + 0 6 16 /6%
  - raised：带一点蓝，0 14 32 rgba(46,111,224,.12)，用于"下一节"卡、解析卡
  - floating：导航坞、胶囊
  - 列表行不加阴影，模糊半径不超过 36
- **玻璃**：只用在导航坞和助手胶囊上（白 74% + 模糊 20 + 1dp 白边）。`lowEnd` 或系统要求减少透明度时，改为白 94%、不模糊。
- **光泽**：页头和关键卡片顶部 40% 叠一层白色 55%→0 的渐变，呼应图标左上的高光。
- **波浪**：今日页头底边、引导页、部分插画使用，曲线直接取自图标。只做静态，不漂移。
- **底部渐隐**：主页面内容在导航坞上方 200px 内渐隐到底色，悬浮层下面不露出被截断的文字。

## 6. 动效

### 6.1 变量

| 变量 | 值 | 用途 |
|---|---|---|
| tap | 90ms | 按下反馈 |
| quick | 160ms | 颜色、图标切换 |
| standard | 260ms | 组件进出、列表项 |
| emphasized | 380ms | 容器变换、填充、页面级 |
| slow | 520ms | 日出入场、庆祝 |
| stagger | 36ms，最多 8 项 | 列表交错 |
| 曲线 | standard (.2,0,0,1) · decelerate (.05,.7,.1,1) · accelerate (.3,0,.8,.15) · reveal (.16,1,.3,1) | 进入用 decelerate，离开用 accelerate，移动用 standard，揭示用 reveal |
| 弹簧 | snappy k520 c38 · gentle k260 c26 · pop k420 c20（质量 1） | 选中指示块 / 弹层与胶囊 / 完成打勾 |

### 6.2 十二个编排模式（原型"动效"页可逐个播放）
1. **日出入场**：按2026-10-09追加反馈，每次真正切回今日／学期页签重播；太阳或月亮沿地平线曲线到当前时刻／周次位置，520ms standard。弹层与后台暂停后继续同一周期，减少动画直接终态，保留原滚动位置。
2. **页面切换 fade-through**：旧页 90ms 淡出，新页 260ms 淡入，同时从 0.98 放大到 1。各页的滚动位置要保留。
3. **列表交错**：每项上移 12px 并淡入，260ms，间隔 36ms，最多 8 项；回到看过的页面不重播。
4. **完成任务**：保存中转圈 → 服务端确认 → 打勾（pop 弹簧）→ 划线 220ms → 行收起 260ms → 回执提示 + 撤销。**划线必须等服务端确认之后**。
5. **选中指示块**：导航坞、分段控件、学期周次都用 snappy 弹簧；被打断时保留速度。
6. **数字滚动**：倒计时、计数变化时逐位上下滚动，260ms。
7. **空档填充**：任务块宽度从 0 填到时长占比，380ms reveal，随后小勾弹出。
8. **容器变换**：课程块变成课程详情、任务行变成任务详情、助手胶囊变成助手面板。380ms standard，内容随后交错进入；返回时收回原位。
9. **胶囊收起**：内容下滑时胶囊收成麦克风圆钮，上滑时展开（gentle 弹簧）。
10. **按住说话**：麦克风轻微呼吸并显示波形；松开完成，上滑取消（沿用现有手势）。
11. **现在标记**：每到整分钟只脉冲一次，光晕从 1 放大到 1.8，900ms。
12. **骨架屏**：按真实布局占位，所有占位块共用一个 1200ms 闪光控制器。

### 6.3 底线
- `MediaQuery.disableAnimationsOf` 为真时：直接到终态，只保留不超过 120ms 的透明度变化；关闭弹簧、视差、交错和日出。
- 页面隐藏、进入后台或被弹层盖住时，暂停一切计时器（`TickerMode`）。
- 动画可以被新的输入打断；弹层下面不播放忙碌动画。
- 触感反馈：
  - 选择类操作（周次、分段、滚轮）用 selectionClick；
  - 完成、开关、打开卡片用 lightImpact；
  - 长按快速添加、开始拖动用 mediumImpact。

## 9. 插画与图标

- **风格（"晴日纸片"）**：
  - 柔和的扁平形状，配轻微渐变；
  - 图形取自图标：日历卡、太阳加三道光、波浪岛、白色高光、小四角星；
  - 不描黑边，不画人物，不放文字。
- **插画清单**（240×180，引导插画 320×240）：

| 文件 | 用在哪里 |
|---|---|
| `empty-today` | 今日没有安排；周课表这一天为空 |
| `all-done` | 待办全部完成 |
| `empty-tasks` | 任务列表为空 |
| `empty-week` | 学期页选中周没有记录 |
| `no-results` | 搜索、筛选无结果 |
| `offline` | 网络失败（配原因 + 重试） |
| `import-timetable` | 还没导入课表；导入入口 |
| `assistant-hello` | 助手新对话 |
| `semester-start` | 还没建学期；学期未开始 |
| `reminder-permission` | 申请通知权限 |
| `onboard-collect / plan / adapt` | 登录页、引导页、学期创建流程 |

- **图标**：
  - 22 个双色图标，24 网格；主色 #2E6FE0、辅色 #8DC2FF，可以按课程色重新着色。
  - 导航图标 8 个（线性/填充成对，形状一致），使用 `currentColor`，用 `ColorFilter` 或 `SvgPicture` 的 `colorFilter` 着色。
- **接入**：
  - 新增依赖 `flutter_svg`；
  - 资源复制到 `apps/mobile/assets/illustrations|icons|brand|patterns/`；
  - 也可以用 `vector_graphics_compiler` 预编译以提速。
  - 文件里的分组 id（`bg / ground / wave / main / sun / sparkle`）留作以后做局部动画。

## 10. 无障碍与性能护栏

- **继续执行 MASTER 的规则**：
  - 关键触控目标 48dp；
  - 系统字号放大到 1.6 倍时布局不溢出；
  - 颜色不能是唯一的信息来源；
  - 有语义标签和键盘焦点；
  - 支持减少动画；
  - 未知时间、缺失字段不补造。
- **模糊**：
  - 只用在导航坞和胶囊上；
  - 滚动时如果掉帧，或者设备性能低，切换为 `lowEnd` 不透明玻璃。
- **重绘控制**：
  - 动画绘制器外面包 `RepaintBoundary`；
  - `AnimatedBuilder` 传入 `child`，避免整树重建；
  - 一个页面最多 1–2 个持续动画。
- **阴影**：只给卡片和悬浮层，长列表的行不加阴影。
- **图片资源**：只用 SVG 或矢量；插画显示尺寸不超过 220dp。
