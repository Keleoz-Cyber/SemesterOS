# 拾日 · 晴日视觉与交互规范

适用于1.0.0。优先级为 [MASTER](../shiri/MASTER.md) 的产品/数据/无障碍约束、[tokens](tokens/tokens.json) 的数值、本文模式。唯一实现为 [lib/ui/v2](../../apps/mobile/lib/ui/v2/)，旧参考实现与原型不再维护。

## 视觉与布局

通透浅底、天蓝到青色/薄荷的品牌渐变、金色日光和柔和波浪。颜色使用tokens语义角色，分类色不表示优先级，图标/文字补充颜色信息。中文跟随系统字体，钟点和数量使用等宽数字；尊重字号放大。列表行不加逐行阴影；模糊只用于导航坞和胶囊，低端/减少透明度用不透明回退。

关键触控目标至少48dp。紧凑七列课表保留单日/列表/详情大入口，不能宣称每格都是48dp。长名、日期和动作按内容换行，不层层套同一个框。

| 内容 | 模式 |
| --- | --- |
| 课程 | 稳定低饱和分类色块，名称和已有教室，点击读完整原课次 |
| 开始时点 | 时刻圆点与标题，未知结束不画成长占用 |
| 待办 | 紧凑清单、截止/剩余与必要风险，服务端确认后完成 |
| 变更 | 按日期归并的旧/新差异，可展开具体课次 |
| 考试 | 独立考试卡、日期与要求、相关复习 |
| 表单 | 必要前置、选填按需添加/删除，键盘与底部动作安全区 |
| 助手 | 查询、候选、预览和回执分开，突出事项/时刻/地点及用户决定 |

## 主页面

- 今日：可折叠天空、下一项、真实空档与待办、时间线、考试和本周条形，保留用户模块选择/顺序。品牌完整缩小并连续过渡到日期，仅天空下沿透明衔接。
- 日程：固定工具栏、周表/列表、日期和筛选。整页横向切周，只高亮真实今天；午晚休用细线，存在开始标记时保留绘图空间。按真实时点/半开区间分组，左轴现在标记不穿过课程。
- 任务：统计、状态分段、紧迫度分组、学习安排；新建与整理通知独立，学习设置靠近所属安排。
- 学期：真实当前周与曲线、周次、所选周内容、资料入口。页头先于状态提示，刷新退场不推动太阳；保留选择与滚动。

## 十二种动效

1. 真实切回今日/学期时沿曲线升起，520ms平滑加减速，终点来自真实时刻或周次。
2. 主页面直接切换，只保留导航选择动效；详情沿现有路由过渡，不加灰色退场覆盖。
3. 列表按稳定身份首次交错，最多8项，看过或流式追加不重播。
4. 完成等待保存成功，然后勾选、划线、收起与限时撤销回执。
5. 选择弹簧只由真实目标变化驱动，同目标刷新不重启，首帧反向也撤销旧目标。
6. 数字只对实际变化滚动，未知不补零/百分比。
7. 空档候选就地展开，确认保存后填充，查询不写入。
8. 课程/任务保留来源对应过渡；助手单一平滑上拉，不叠加胶囊缩放。
9. 胶囊只向左伸缩，右侧麦克风和触控固定，录音子树保留；文字/图片分阶段淡出。
10. 按住、松开、上滑取消沿原录音流程，后台/账号切换清理作用域。
11. 真实分钟变化脉冲，隐藏/离开当天停止计时。
12. 首次加载用真实布局骨架，刷新用不改变布局的覆盖提示；退场提示保留自然尺寸，关闭后释放不需保留的子树。

后台、隐藏、弹层覆盖暂停，同周期恢复后继续；减少动画直接终态，隐藏动作不留点击/焦点/语义。装饰动效不允许回顶、重载数据或重挂载状态。
