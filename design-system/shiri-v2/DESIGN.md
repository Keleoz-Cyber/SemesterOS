# 拾日“晴日”界面说明

这份说明是照着现在的 Flutter 代码和 `tokens/tokens.json` 写的，改页面、控件、动画的时候翻一下。它只讲已经做成这样的东西——某个组件存在，不等于所有页面都在用它。

业务和无障碍上的硬规则在[界面维护规则](../shiri/MASTER.md)。

## 颜色

App 现在只有浅色主题，另外做了一套高对比适配。深色的数值和 `shiriDarkTheme()` 都写在代码里了，但主入口没接切换，所以别在文档或者演示里说“支持深色模式”。

| 用途 | 浅色数值 |
| --- | --- |
| 页面背景 | `#F3F7FC` |
| 浅色背景带 | `#EAF3FD` |
| 卡片、弹窗表面 | `#FFFFFF` |
| 输入框、选择轨道底色 | `#EEF3F9` |
| 主要文字 | `#142238` |
| 次级文字 | `#33435C` |
| 辅助文字、图标 | `#5B6B82` |
| 较弱文字 | `#8291A7` |
| 主按钮、选中状态 | `#2E6FE0` |
| 浅蓝选中底色 | `#EAF2FF`、`#D7E7FF` |
| 分隔线 | `#E4ECF5` |

品牌渐变是蓝 `#4CA4FF`、青 `#63CFE9`、薄荷绿 `#8DE0B2`，只用在装饰、图标和少量强调上。太阳是 `#FFEBA6` 到 `#F6C86B`。正文先保证清楚，别为了“通透”把整段文字调淡。

数值来自 JSON 的 `color`、`gradient`，以及 Flutter 里的 `ShiriColors`、`ShiriBrand`、`ShiriGradients`。旧的 `CampusColors` 兼容名字还在用，改通用颜色时得连它和 Forui 主题一起看，不然同一个按钮会出现两种蓝。

## 字体和间距

用平台默认字体，数字开等宽特性。App 没有为了排版去打包一套中文字体，测试里可以单独指定字体。

| 文字 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 大日期 | 34 / 40 | 700 |
| 页面标题 | 26 / 32 | 700 |
| 分组、面板标题 | 20 / 26 | 600 |
| 卡片标题 | 17 / 24 | 600 |
| 正文 | 16 / 24 | 400 |
| 强调正文、按钮 | 16 / 24 | 600 |
| 辅助说明 | 14 / 20 | 400 |
| 标签 | 13 / 18 | 600 |
| 日期轴等小字 | 12 / 16 | 500 |

这是通用样式。密集课表里的标题和教室用的是更紧的字号，完整信息靠详情和当天列表看，别把这套局部字号推广到正文。

间距常用 4、8、12、16、20、24、32 dp。页面两侧标准是 20 dp，今日页头部在宽度不超过 360 dp 时用 16 dp。卡片内 16 dp，宽松些的 20 dp。分组之间 28 dp，条目之间 12 dp。注意页面里还有不少地方是写死的数值，改一个 token 不代表全站自动跟着变。

圆角分 8、12、16、20、28 dp 和胶囊几档。小圆角给输入框和小控件，大圆角给卡片和弹层。不是每一行内容都需要外框。

## 导航和助手入口

底部四个入口固定：今日、日程、任务、学期。导航坞基础高 64 dp，圆角 28 dp，左右和底部各留 12 dp；文字放大时按标签实际高度长高。选中块 56 dp 宽、32 dp 高，在入口之间连续移动。

导航坞是白色 74% 透明表面，模糊 20，带浅色边缘，外阴影现在是关掉的。低性能、高对比或者开了减少动画时，换成 94% 不透明的实底。模糊统一由 `GlassSurface` 处理。

助手入口基础高 52 dp，圆角 26 dp，跟导航坞隔 10 dp。收起后是右边一个 52 dp 的入口：外形往右收，麦克风位置不动，文字先淡出，图片入口后淡出。录音那棵子树要单独留着，不能在动画中间重建麦克风按钮——一重建，按住的录音就断了。

往下滚收起，往上滚展开。轻点输入入口打开助手，麦克风还是按住说话。底部导航和分段选择不加整块灰色按压反馈，但键盘焦点、读屏标签、实际选中状态都得留着。

四个页面用 `IndexedStack` 保留，滚动位置按账号和学期分开记。底部切页现在不做整页灰色渐退。普通路由还是用主题里的页面过渡，这两种切换别搞混。

助手用统一的可拖动弹层，大概占可用高度 90%，打开用 260 ms 的 `easeOutCubic`。键盘避让交给 `showAppSheet`。胶囊外形变成面板这个动画现在没有实现，说明和演示里都别这么讲。

## 各页面怎么排

### 今日

上面是可折叠的天空页头，日期和周次最先出来。下面由当前或下一项安排、今日内容、可选模块组成，显示哪些模块由首页设置决定。默认的模块有近期截止、学习安排、空档与待办、近期考试；本周忙闲、学期进度、时间统计、呼吸练习要单独开。

下一项安排用明显的字号把时间和标题顶出来；日程按时间顺序排；待办保持清单的样子；考试单独一个入口。空档推荐能就地展开看，确认之后才显示“已安排”。

页头滚动时，品牌名和紧凑日期在同一块区域里对着换；天空底边用 12—18 dp 的淡出接下面的内容，字和按钮不能被吃掉。天空按北京时间分四段：05:00—08:00、08:00—16:30、16:30—19:00、夜间，交界前后各留 20 分钟做颜色混合。

太阳或月亮每次真正进今日页才沿弧线升起来，用 520 ms。页面被助手挡住或者 App 退到后台就暂停，关面板不算“又进了一次”。

### 日程

周课表和列表用分段控件切。周课表左边留时间轴，“现在”的标记在轴上，不横穿课程文字。今天那一列和日期头有浅蓝强调，但只标真正的今天；翻到下一周时，同一个星期几不能被当成今天。

切周用 `CalendarWeekPager` 的 `PageView`。拖动时相邻两周一起走；点箭头用 300 ms 的 `easeOutCubic`。手拖到稳定停在一周之后才提交所选周，不然滑过中间页会一路发请求。

教学节次和课间休息在视觉上压过，但时间判断还是真实钟点。空着的间隔可以画斜纹带，不能因为视觉压扁就把事件时长改短。只有开始时间的日程画成开始标记，不要画成一块长度未知的占用。

日程种类除了颜色，形状和标记也不一样：

| 内容 | 现在长什么样 |
| --- | --- |
| 课程 | 浅色底，左侧 3 dp 强调条 |
| 个人日程 | 白底，绿色描边，活动图标 |
| 学习安排 | 浅蓝底，虚线描边，“计划”标签 |
| 考试 | 珊瑚浅底，“考试”标签 |
| 截止事项 | 旗子和时间标记，不冒充课程 |

课程配色有八组：晴蓝、薄荷、青湖、藤紫、杏橙、樱粉、麦黄、雾灰。课程标题会稳定映射到其中一组，换个页面也是同一个颜色。课表块圆角 11 dp，点开看完整信息。多条重叠的时候，得让用户进去看明细，不能拿“2 项”当完整内容。

### 任务和学习安排

先看任务统计和待处理、已完成、已取消三种状态，再往下是当前清单。分段控件固定在会随状态变化的操作上面；安排任务、整理通知这些操作跟着当前内容显示，不能让分段控件中途跳位置。

任务用行式清单，显示标题、时间、状态，完成入口要明显好点。学习安排显示时间段、固定状态和关联的任务；学习时间设置从相关入口进，别插在任务中间把节奏打断。

任务完成会依次经过未完成、提交中、完成。`CompletionCheck` 只有接到“已完成”才画结果。数字变化用 `RollingNumber`，只滚变的那几位，读屏念最终值。

### 学期

学期用地平线表示进度，周次选择放在一条连续的区域里，选中之后内容的方向保持连贯。近期考试、截止、变化记录各有入口，别把一串周次标题堆成同样大的卡片。

地平线上的太阳用当前进度，配一个独立入场动画；主壳的进入编号决定重新进入时放不放，开了减少动画就直接到位。进度必须从真实学期日期算，别加什么“学习完成百分比”的估算。

### 标签

标签页保持搜索框加按用途分组的列表。自动整理是静默的，不弹完成提示，也不再加一排分类筛选。名称那一行能点，显示关联了多少条，点开进真实记录；右边更多菜单里留着手动重命名和合并。

关联列表显示标题、类型、时间、地点和完成或取消状态；别的学期补上学期的名字，点进去进对应详情。加载、出错、重试、空状态分开做，切账号后把旧结果清掉。合并只改归属，标题、原文、时间原样不动。控件继续用 `AppTile` 和现有主题。

### 助手、详情和表单

用户消息和助手结果的对齐、底色不一样。结果按用途分成查询明细、修改预览、冲突核对、保存回执，不要所有回答都套同一张卡片。第一层说清做什么、什么时候、在哪儿，完整来源和补充信息按需展开。

详情先给名称、时间、地点、当前状态，再分组显示来源和相关记录。表单用统一输入框、可增删的补充字段和时间滚轮。公共弹层最大内容宽 720 dp，顶部圆角 28 dp，键盘避让统一做。

空状态用相关插画加一句事实加一个动作；加载用跟内容大小接近的骨架。错误留在出错的地方附近，别拿反复弹的成功提示去盖住实际状态。

## 动效参数

| 参数 | 数值 | 一般用在哪 |
| --- | --- | --- |
| 按下 | 90 ms | 轻微按压 |
| 快速反馈 | 160 ms | 小范围反馈 |
| 一般变化 | 260 ms | 内容更新、数字变化、展开 |
| 明显过渡 | 380 ms | 通用弹层默认过渡 |
| 慢入场 | 520 ms | 太阳、地平线入场 |
| 列表错开 | 每项 36 ms，最多前 8 项 | 第一次出现的短列表 |
| 骨架循环 | 1200 ms | 加载扫光 |

选中指示用质量 1、刚度 520、阻尼 38 的弹簧。胶囊收放是刚度 260、阻尼 26；完成反馈是刚度 420、阻尼 20。这些值都在 `ShiriMotion` 里，别在页面里另写。

自定义卡片可以用 `Pressable`：默认按下去缩到 0.97，课表块用 0.96。它不会自动扩大触控区，调用方还得给够 48 dp。列表里的普通行不需要整行缩放。

列表错开入场按稳定标识记，同一个会话里返回页面不重放。内容变了要保住输入、滚动、选择的状态；用户快速反着操作时，从当前位置接着走，别先跳回起点。

## 字号、减少动画、性能

文字缩放走 `MediaQuery.textScaler`，不要写死成 1.0。页面标题、底部导航、周次选择都是按实际文字量的；新加的东西还得自己看窄屏和大字号，不能推断“应该没问题”。

开了减少动画或者无障碍导航之后，弹簧和位移直接到终态，太阳入场和扫光停掉，简单的透明度变化最多 120 ms。隐藏的页面和后台把 ticker 停掉。

`ShiriPerformance` 会在前台连续 8 帧光栅耗时超过 32 ms 时，给这次会话开低性能回退。这是运行时的策略，不是性能成绩，别拿它当“优化效果”。回退会关掉玻璃模糊，高对比和减少动画也会触发实色显示。动画区加 `RepaintBoundary`，普通列表行别加阴影和大面积模糊。

## 改完怎么检查

改通用数值要同步 JSON、`shiri_tokens.dart` 和必要的兼容层。新加动画先看现有动效组件，想清楚什么时候触发、终态是什么、连续快点会怎样、开了减少动画怎么办，再接页面。

改完至少看这几种：普通字号；360 dp 宽加 1.6 倍字号；减少动画；高对比；键盘和底部面板；连续切页、切周、反向拖。碰到完成、保存、冲突、撤销、导入、录音，还得回头核数据和原有的行为测试。

截图要从跑着的 App 里取，记下尺寸和状态。这里没附一套跟代码同步的目标效果图，读源码也不算真机性能验收。
