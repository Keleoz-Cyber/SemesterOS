# 拾日“晴日”界面说明

本说明根据当前 Flutter 代码和 `tokens/tokens.json` 编写，供修改页面、控件和动画时查阅。它描述已经采用的做法；不能仅因为某个组件存在，就把它说成所有页面都已使用。

共同的业务与无障碍要求见 [界面维护规则](../shiri/MASTER.md)。

## 颜色与主题

当前 App 使用浅色主题，并提供高对比度适配。深色数值和 `shiriDarkTheme()` 已存在，但主入口没有接入深色主题切换。

| 用途 | 浅色数值 |
| --- | --- |
| 页面背景 | `#F3F7FC` |
| 浅色背景带 | `#EAF3FD` |
| 卡片、弹窗表面 | `#FFFFFF` |
| 输入框、选择轨道底色 | `#EEF3F9` |
| 主要文字 | `#142238` |
| 次级文字 | `#33435C` |
| 辅助文字、图标 | `#5B6B82` |
| 较弱文字 | `#8291A7` |
| 主按钮、选中状态 | `#2E6FE0` |
| 浅蓝选中底色 | `#EAF2FF`、`#D7E7FF` |
| 分隔线 | `#E4ECF5` |
| 成功 | `#0F7F63`，浅底 `#E3F6EE` |
| 警告 | `#96620A`，浅底 `#FFF4D6` |
| 错误 | `#C2412D`，浅底 `#FDECE8` |

品牌渐变由蓝 `#4CA4FF`、青 `#63CFE9` 和薄荷绿 `#8DE0B2` 组成，用在装饰、图标和少量强调处。太阳使用 `#FFEBA6` 到 `#F6C86B` 的渐变。正文应先保证清晰，不要为了“通透”降低整段文字透明度。

数值来源是 JSON 的 `color`、`gradient` 和 Flutter 的 `ShiriColors`、`ShiriBrand`、`ShiriGradients`。旧的 `CampusColors` 兼容名称仍在使用；修改通用颜色时要一起检查它和 Forui 主题，避免同一按钮出现两种蓝。

## 字体与间距

使用平台默认字体，数字采用等宽数字特性。App 没有把一套额外中文字体打包成产品依赖；测试可以单独指定字体。

| 文字 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 大日期 | 34 / 40 | 700 |
| 页面标题 | 26 / 32 | 700 |
| 分组、面板标题 | 20 / 26 | 600 |
| 卡片标题 | 17 / 24 | 600 |
| 正文 | 16 / 24 | 400 |
| 强调正文、按钮 | 16 / 24 | 600 |
| 辅助说明 | 14 / 20 | 400 |
| 标签 | 13 / 18 | 600 |
| 日期轴等小字 | 12 / 16 | 500 |

这是通用文字样式。密集课表内的标题和教室使用更紧凑字号，完整信息通过详情和当天列表阅读；不要把这些局部字号推广到普通正文。

常用间距为 4、8、12、16、20、24、32 dp。标准页面两侧留 20 dp；今日页头部在不超过 360 dp 宽时使用 16 dp。卡片内部常用 16 dp，宽松卡片 20 dp。通用分组间距 28 dp、项目间距 12 dp。页面调用处仍有局部数值，不能假设所有页面都会自动跟着一个 token 改动。

圆角有 8、12、16、20、28 dp 和胶囊形几档。用小圆角处理输入和小控件，较大圆角处理卡片与弹层，不需要给每一行内容加外框。

## 导航和助手入口

底部固定四个入口：今日、日程、任务、学期。导航坞基础高度 64 dp，圆角 28 dp，两侧和底部留 12 dp；文字放大时会按标签实际高度增高。选中块宽 56 dp、高 32 dp，在入口间连续移动。

导航坞使用白色 74% 透明表面、20 的模糊参数和浅色边缘，当前关闭外阴影。低性能、高对比或减少动画时改用 94% 不透明的回退表面。模糊由 `GlassSurface` 集中处理。

助手入口基础高度 52 dp，圆角 26 dp，与导航坞相隔 10 dp。收起后为右侧 52 dp 的入口：外形向右收拢，麦克风留在同一个位置，文字先淡出，图片入口随后淡出。麦克风录音子树独立保留，不能在动画中重建录音按钮。

向下滚动收起、向上滚动展开。输入入口轻点打开助手，麦克风沿用按住说话逻辑。底部导航和分段选择不使用整块灰色按压反馈；键盘焦点、读屏标签和实际选中状态仍保留。

四页由 `IndexedStack` 保留，配合账号与学期区分滚动位置。当前底部切页不做整页灰色渐退。普通路由仍使用主题中的页面过渡，不能把两种切换混为一谈。

助手使用统一的可拖动弹层，约占可用高度的 90%，当前打开时使用 260 ms 的 `easeOutCubic` 过渡。键盘避让交给 `showAppSheet`。当前实现没有把胶囊外形变换成助手面板，不应在说明或演示中声称已有这一效果。

## 不同内容怎么排

### 今日

可折叠天空页头在上，日期和周次先显示。内容由当前或下一项安排、今日内容和可选模块组成，首页设置控制模块显示。默认可选模块包括近期截止、学习安排、空档与待办、近期考试；本周忙闲、学期进度、时间统计和呼吸练习可以另外开启。

下一项安排用明显时间和标题表达；日程沿时间顺序排，待办保持清单形式，考试采用独立入口。空档推荐展开就地预览，确认后才显示已安排结果。

页头滚动时，品牌名和紧凑日期在同一区域逐步换显；天空底边用 12—18 dp 的淡出边缘衔接内容，文字与操作保持清楚。天空按北京时间分为 05:00—08:00、08:00—16:30、16:30—19:00 和夜间，边界前后合计 20 分钟混合颜色。

太阳或月亮每次真正进入今日页时沿弧线升起，入场使用 520 ms。页面被助手遮住或进入后台时暂停，不把面板关闭误判成又一次进入。

### 日程

周课表与列表由分段控件选择。周课表左侧保留时间轴，“现在”标记在轴上，不横穿课程文字。今天的列与日期头有浅蓝强调，只标记真实今天；查看下一周时不把相同星期误当成今天。

切周使用 `CalendarWeekPager` 的 `PageView`。拖动时相邻两周一起移动；箭头切换使用 300 ms 的 `easeOutCubic`。手动拖动稳定停在一周后再提交所选周，避免经过中间页时不断请求数据。

教学节次与休息时段经过视觉压缩，时间判断仍用真实钟点。无占用的间隔可以显示斜纹带，不能因为压缩视觉高度就改短事件时长。只有开始时间的日程作为开始标记处理，不画成未知长度的占用大块。

日程种类除了颜色，还有形状和标记差异：

| 内容 | 当前样式 |
| --- | --- |
| 课程 | 课程浅色底、3 dp 左侧强调条 |
| 个人日程 | 白底、绿色描边、活动图标 |
| 学习安排 | 浅蓝底、虚线描边、“计划”标签 |
| 考试 | 珊瑚浅底、“考试”标签 |
| 截止事项 | 旗帜和时间标记，不冒充一段课程 |

课程配色有晴蓝、薄荷、青湖、藤紫、杏橙、樱粉、麦黄和雾灰八组，课程标题映射到稳定配色。课表块圆角 11 dp，点开可以查看完整信息。多项重叠时应让用户进入明细，不能把“2 项”当成完整内容。

### 任务与学习安排

先看任务统计和待处理、已完成、已取消三种状态，再看当前清单。分段控件位置固定在随状态变化的操作上方；安排任务、整理通知等操作根据当前内容显示，不能推动分段控件中途跳位。

任务用行式清单显示标题、时间和状态，完成入口清楚可点。学习安排使用时间段、固定状态和任务关联；学习时间设置从相关入口进入，不插在任务之间造成断裂。

任务完成依次经历未完成、提交中和完成三种显示。`CompletionCheck` 只有接到已完成状态才画完成结果。数字变化用 `RollingNumber`，只滚动变化的字符，读屏读取最终值。

### 学期

学期用地平线表现进度，周次选择放在连续的一条区域中，所选周内容保持方向连续。近期考试、截止和变化记录有各自入口，不把重复周次标题堆成同样的大卡片。

地平线上的太阳使用当前进度和独立入场动画；主壳的进入编号控制重新进入时播放，减少动画时直接到位。进度必须来自实际学期日期，不添加估算的“学习完成百分比”。

### 助手、详情和表单

用户消息与助手结果有不同对齐和底色。结果根据用途显示为查询明细、修改预览、冲突核对或保存回执；不把所有回答套成一张相同卡片。首层说清做什么、何时、哪里，完整来源和补充信息按需查看。

详情先显示名称、时间、地点和当前状态，再分组显示来源及相关记录。表单使用统一输入框、可添加或移除的补充字段和时间滚轮。共同弹层最大内容宽度 720 dp，顶部圆角 28 dp，统一避让键盘。

空状态使用相关插画、一句事实和一个动作；加载时使用与内容大小接近的骨架。错误留在相关内容附近，不能用反复出现的成功提示替代实际状态。

## 动画参数和使用方法

| 参数 | 数值 | 常见用途 |
| --- | --- | --- |
| 按下 | 90 ms | 轻微按压 |
| 快速反馈 | 160 ms | 小范围反馈 |
| 一般变化 | 260 ms | 内容更新、数字变化、展开 |
| 明显过渡 | 380 ms | 通用弹层默认过渡 |
| 慢入场 | 520 ms | 太阳、地平线入场 |
| 列表错开 | 每项 36 ms，最多前 8 项 | 初次出现的短列表 |
| 骨架循环 | 1200 ms | 加载扫光 |

选中指示使用质量 1、刚度 520、阻尼 38 的弹簧。胶囊收放采用刚度 260、阻尼 26；完成反馈采用刚度 420、阻尼 20。这些数值在 `ShiriMotion` 中集中定义。

自定义卡片可用 `Pressable`：默认按下缩到 0.97，课表块使用 0.96。它不自动扩大触控区域，调用处仍需提供至少 48 dp 的可点范围。列表普通行不必整体缩放。

列表错开入场按稳定内容标识记录，同一会话返回页面不重复播放。内容修改要保留输入、滚动和选择状态；操作被快速反向触发时，从当前位置继续，不先跳回起点。

## 字号、减少动画与性能

文字缩放使用 `MediaQuery.textScaler`，不固定为 1.0。页面标题、底部导航和周次选择都有按实际文字测量的处理；新增内容仍需检查窄屏和大字号，不能据此推断所有新页面自动合格。

减少动画或无障碍导航开启时，弹簧和移动直接到终态，太阳入场和扫光停止，简单透明度变化最多 120 ms。隐藏页面和后台停止 ticker。

`ShiriPerformance` 在前台连续 8 帧光栅耗时超过 32 ms 时启用本次会话的低性能回退；这是一项运行策略，不是性能测试成绩。回退关闭玻璃模糊，高对比和减少动画也可触发实色显示。动画区使用 `RepaintBoundary`，普通列表行避免阴影和大面积模糊。

## 修改与检查

改通用数值时同步 JSON、`shiri_tokens.dart` 以及必要的兼容层。新增动画先查看现有动效组件，确定触发时机、终态、快速重复操作和减少动画表现，再接入页面。

改完至少检查：普通字号；360 dp 宽加 1.6 倍字号；减少动画；高对比；键盘与底部面板；连续切页、切周和反向拖动。涉及任务完成、保存、冲突、撤销、导入或录音时，还要复核实际数据与既有行为测试。
