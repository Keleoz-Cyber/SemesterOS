# 第二批：事项记录、文字解析与提醒

记录日期：2026-09-20。开发分支：`codex/android-foundation`。本批接续真实课表导入和校园风界面。

## 已实现的使用流程

“＋记录”提供文字快速记录、作业、考试、个人任务及原有课程导入。手工和AI候选共用核对表单；AI候选可修改事项类型，原文、推断标记和需核对问题直接展示。用户确认后才保存，取消核对不会生成正式事项。

时间支持具体时刻、仅日期、学期周次、日期范围及待确认。只有日期时不补造午夜，任务可由用户确认当天结束前口径；没有耗时保持null。暂定考试与用户已核对相互独立，复习耗时通过个人任务记录。

今日页增加待处理事项；“计划”入口现提供当前学期事项列表、详情、编辑、完成、取消和恢复。原始来源不可覆盖，修改依据和快照可查看。事项、草稿、提醒和缓存按账号隔离，跨账号请求拒绝；正式修改使用版本校验和幂等键。

## 提醒

录入页可选择并核对多条提醒，详情可独立增加、修改、停用。相对提醒展示计算后的时刻；绝对提醒明确指定北京时间。任务提供提前1天/2小时预设；考试增加14天开始复习/7天预设，选择复习提醒不创建复习任务。

只有日期/周次的考试允许独立核实通知提醒，普通考前提醒等待时间锚点。修改日期重算相对规则；已过期不补发；不再适用的绝对规则及改期后产生的重复触发时刻暂停核对。完成/取消会停用规则；恢复事项不自动重启旧提醒。

Flutter使用`flutter_local_notifications 22.3.1`和`timezone 0.11.1`，采用Android普通定时模式。系统权限按用户操作申请；拒绝后规则和App内记录保留。应用恢复前台会校正清单，插件配置了开机/更新后的重建接收器；本批没有做整机重启测试。系统同步状态与实际送达状态分开显示，不承诺分钟级必达。

通知同步串行处理，并绑定账号代次。退出时撤销本机提醒。保存回执先更新本机清单，旧GET不得覆盖新回执；即使后续拉取失败，仍能撤销已完成事项的旧通知。账号切换后旧请求不能重新显示或安排另一账号的提醒。数量超过450条时只安排最近450条，界面明确提示，其余保留App内展示。

## 真实模型接入

用户指定`deepseek-flash`；模型列表接口确认该标识可用。使用服务端Chat Completions JSON输出，关闭思考模式；依据[DeepSeek JSON输出文档](https://api-docs.deepseek.com/guides/json_mode/)和[接口合同](https://api-docs.deepseek.com/api/create-chat-completion/)。

密钥只保存在仓库根目录已忽略的`.env`，不在客户端、仓库和验证报告中。仅发送本次原文、解释日期所需的参照时间与当前学期课程候选。结果经过schema、课程白名单、证据摘录和时间精度校验；模型不得确认日末口径。记录供应商、模型、schema/prompt版本、耗时及用量。

异常响应显示可理解的错误并保留原文；无配置时明确不可用。非新增意图不会夹带创建事项；自然语言修改和现实变化应用留待后续批次。模型格式解析失败最多重试一次，未通过校验的结果不能保存为候选事项。

## 运行与复核

正常使用先按README启动API并运行Android App。本批新增原生通知插件，需要完整重新运行App，单纯热重载不足以加载插件。数据库新增迁移由`scripts/dev.ps1 -Action Api`应用；现有课表不重置。

`scripts/verify_text_model.py`和`scripts/verify_items_api.py`会调用真实模型；后者只面向已启动的本机API并创建合成QA账号。普通pytest/Flutter测试不调用真实模型。

`scripts/verify_android_items.py`仅在模拟器App已处于登录页时运行，创建`qa_ui_`合成账号，验证新入口和任务显示后退出；不自动退出已有用户。脚本不保存或输出密码及令牌。

原生通知检查入口为`apps/mobile/test_support/notifications_smoke.dart`，仅用于开发验证。它不初始化账号、课程或应用缓存，只安排固定标识的合成通知并清理。需在模拟器授权通知、收到后点击；通过以`QA_NOTIFICATION_PASS`为证据。使用后重新运行`lib/main.dart`。
