## 3. 河南工业大学教务接入证据

### 3.1 官方入口与当前登录页

学校发布的[综合教务系统访问说明](https://www.haut.edu.cn/info/1311/508351.htm)列出教务账号和统一身份认证两种登录方式；该说明发布于2020年，属于历史官方依据。

当前[官方登录页](https://jwglxt.haut.edu.cn/jwglxt/xtgl/login_slogin.html)显示河南工业大学教学综合信息服务平台和正方V-9.0标识。本机本次GET返回HTTP 200。公开表单包含用户名、密码和CSRF字段；当前公开[登录脚本](https://jwglxt.haut.edu.cn/jwglxt/js/globalweb/login/login.js?ver=29817244)包含获取公钥并使用RSA加密密码的逻辑。

这些证据说明登录入口和前端协议可研究，不说明认证成功、移动端可登录或课表接口可用。本次没有提交账号密码、验证码，也未读取登录后的个人数据。

### 3.2 已有该校适配实践

公开仓库[yusixian/AISchedule_myparser](https://github.com/yusixian/AISchedule_myparser)声明适配河南工业大学新正方，并在2025-03-13的更新说明中加入接口读取方式。这是作者的历史适配记录，不能直接视为2026年当前版本可用。

阅读其[provider源码](https://raw.githubusercontent.com/yusixian/AISchedule_myparser/main/new_provider.js)发现，它利用已登录网页会话访问课表查询页，并向以下路径提交学年、学期参数：

```text
/jwglxt/kbcx/xskbcx_cxXskbcxIndex.html
/jwglxt/kbcx/xskbcx_cxXsKb.html
参数：xnm、xqm
预期列表：kbList
```

这些是第三方源码中观察到的校内前端接口路径，非已验证的公开开放API。本次未向这些路径发送课表查询请求。实际路径、菜单参数、学期编码及CSRF要求均需登录后核实；不能把“第一/第二学期”直接假设为固定的1/2编码。

其[parser源码](https://raw.githubusercontent.com/yusixian/AISchedule_myparser/main/new_parser.js)映射课程名称、教师、地点、星期、周次和节次字段，提供JSON及页面解析两条线索。不能原样移植：例如provider菜单分支引用未定义的`i`，parser还会合并同一时段课程，不适合本项目保留真实冲突的规则。代码复用许可尚未核实，后续应独立实现适配器或先核实授权。

另有[WakeUp官方导入说明](https://www.wakeup.fun/doc/import_from_eas.html)介绍在App内登录教务、进入课表页面后导入的操作方式，支持把“原站登录后读取”作为候选交互；这不代表WakeUp当前该校适配或本项目实现已经验证。

### 3.3 接入使用事宜已由用户协调确认

学校教务处2026-09-09的[体育必修课选课通知](https://jwc.haut.edu.cn/info/1114/13331.htm)明确禁止使用“兜圈子校园”等第三方微信小程序登录。

用户于2026-09-19明确表示上述接入使用事宜已经商量好，可以推进。以用户本次确认为项目依据，不再将该事项列为待确认项、要求重复确认或阻塞开发。以上通知仅保留为调研来源记录；该协调确认不替代真实登录、课表读取和Android兼容性的技术验证。

## 4. 候选接入方式

这是实施建议，须经Android真机和真实账号验证后才能确定为已支持能力。

1. 用户先登录学期OS账号，选择河南工业大学及目标学期。
2. App打开学校原始HTTPS登录页，用户自行完成密码、验证码或统一认证；不在聊天或学期OS自建表单中索取教务密码。
3. 进入本人课表页，在同一受限网页登录会话中读取课表。优先读取实际页面所用的结构化响应，页面解析作为备选。
4. 本地只提取课程所需字段，展示学期、周次、节次、地点等预览；发现未知字段或信息缺失时提示核对。
5. 用户确认后，将必要的课表数据上传至本人学期OS账号；教务密码、Cookie和认证令牌不发送给学期OS后端或模型。
6. 再次导入先进行差异预览和实例匹配，保留通知来源、用户修正与变更历史，不直接全量覆盖；失败不改动已保存课表。

WebView仅对核实的学校域名与课表页面开放必要读取能力；不得对任意网页暴露通用原生调用桥。退出或切换账号时清理对应教务会话和敏感缓存。学校要求校园网或官方VPN时沿用其正常访问方式。

产品文档中“教务同步”在V1指用户主动重新导入并确认差异；当前不承诺长期保存密码或后台定时登录。登录会话失效时请用户重新进入学校认证流程。

文件、截图和手工录入继续作为兜底。它们能维持产品闭环，但不能代替“登录导入已完成”的验收证据。
