# V2 完整高保真原型说明

2026-09-26。本轮补齐日程、计划和学期，连同已有今日、AI助手、统计分析构成完整设计原型。它仍是可点击网页，不是已经改造完成的Flutter App，不连接真实账号、模型、教务或服务器。

## 页面与操作

| 页面 | 已实现的原型交互 |
| --- | --- |
| 今日 | 日期选择、课程、其他安排、任务截止提示、统计入口、快捷模块开关；任务完成后不再显示其紧急截止提示 |
| 日程 | 周课表／按天切换、前后周、选择周次、回本周、类型筛选、重叠安排分列、时段滚动和日程详情 |
| 计划 | 待完成／已完成、任务详情、已有学习时段、实际投入记录、完成任务、撤销完成、进度历史、可学习时间 |
| 学期 | 20周周带、当前周定位、按周时间轴、考试／截止／活动筛选、空周、跳到该周日程、课程与考试清单 |
| AI助手 | 示例录入、分类标签与提醒核对、组会保存、独立重排确认、回执、撤销与重复通知处理 |
| 统计 | 时间范围、主分类与标签、已安排／实际记录、数值和图形过渡、日期明细和空数据 |
| 导入 | 搜索学校、已适配／未适配状态、学校登录说明、合成课表预览、重复课表导入回执 |

日程周网格不支持直接拖动学校课程；重叠事项使用区间分组和列分配，而不是后画的卡片盖住前一条。狭窄屏幕在网格内部滚动，不导致整个页面横向溢出；点击某天后可切换按天列表查看完整标题。

## 记录进度与统计的关系

“记录进度”可填写本次实际投入时长，或明确标记任务完成。实际投入不自动从剩余工作量中扣除；投入40分钟不等于一定完成40分钟工作。

在本地示例中完成Java报告会取消它剩余的60分钟学习安排和待提交节点，保留组会等其他日程。若用户填写40分钟实际投入，实际统计增加40分钟；不填写则不产生虚构时长。撤销这条完成记录会恢复原计划和截止节点，并删除对应的本次实际记录。

任务完成后，报告重排示例明确提示不再需要安排，不因访问历史入口把任务重新排进日历。原型仅模拟这一闭环；正式服务仍需版本校验、幂等、提醒同步和跨设备冲突处理。

## 状态与限制

- 离线可查看已有数据，保存进度、应用调整、撤销和示例导入会被阻止并说明原因。
- 可从桌面审阅面板触发“加载失败”。日程仍显示已有记录，重试恢复正常状态；离线时不声称更新成功。
- 没有已完成任务、某天没有某类安排、未来周没有考试等情况均有对应空状态。
- 概率论考试只标注暂定第14周，未补造日期与时刻，可跳转到复习任务。
- 学校原站、未预置任务排程、自由对话等能力仍如实说明未接入，不把按钮跳转或静态示例当成实际完成。

品牌名和Logo仍是占位；真实模型、Flutter布局、通知送达、数据库迁移以及真机流畅度未在本轮实施。完整设计原型不代表生产版本验收。

## 建议查看路径

1. 今日进入AI组会示例，添加组会，再独立应用／撤销个人计划调整。
2. 日程切换周网格和按天列表，查看组会与Java报告同时存在时的重叠显示。
3. 计划记录Java报告投入40分钟并标记完成，查看已完成列表和统计变化，再撤销完成记录。
4. 学期选择第14周，筛选考试，查看暂定考试与复习任务；选择第20周查看空状态。
5. 日程进入学校选择，搜索一个未适配名称，再体验已有示例课表的重复导入回执。
