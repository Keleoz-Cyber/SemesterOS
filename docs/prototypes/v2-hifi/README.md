## 可以体验

- 今日：一周日期选择、课程与个人安排、详情、统计入口、快捷模块显示／隐藏。
- AI：输入、明确的示例处理步骤、分类与多标签编辑、提醒修改、保存组会、独立重排确认、结果回执和撤销。语音波形和图片入口为示意，不采集或上传媒体。
- 统计：本周／本月／本学期、已安排／实际记录、主分类、多个标签、按天选择及明细列表；范围较大时将日期汇总为可点开的时间段。
- 动效：日期与按钮选中、面板进入、处理阶段、结果勾选、数值变化、条形图过渡、语音波形。支持系统减少动画和原型的减少动画开关。
- 异常状态：未知输入明确说明未接入AI，离线时阻止保存与应用，统计空数据与未记录时长清晰显示。

## 数据含义

使用固定2026-09-23 11:40和合成数据，包含从8月31日开始的8周预置安排；学期筛选范围覆盖20周，不假装其余周已经有完整课表。

每周7次课程，每次110分钟；另有复习60分钟、项目讨论60分钟、材料办理30分钟、跑步45分钟。本周另有Java报告计划60分钟；添加新组会再增加60分钟。因此添加组会后本周已安排1085分钟，约18.1小时。

主分类时长按安排相加，重叠安排分别计时，不等于区间并集占用。多标签筛选是满足任一标签的记录集合，每条记录只计一次。截止节点没有时长，不参与时长求和。

实际记录是独立的合成输入，课程不自动计为已出席。本周只有已记录的复习和项目讨论各50分钟，共100分钟；未记录的课程显示未知，不当成零。这里没有学习效率评分。
