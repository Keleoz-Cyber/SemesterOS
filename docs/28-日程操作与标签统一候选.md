## 本轮完成

1. 助手支持查询具体课次、记录调课/停课/补课，以及暂定考试录入和已有考试改期。课程与个人计划分开；复习截止是否跟随考试变更明确显示。已有同名歧义必须由用户选择，支持一次选择整组课次。
2. 一份通知可以生成多事项分组。勾选后重新计算实际冲突，一次原子保存所选组；失败全部回滚，重复确认不会再次添加。提醒缺少具体时刻时追问，不把日期擅自变成 23:59。
3. 保存后提供统一撤销预览；也可自然语言要求撤销，由助手查询真实操作回执再准备。撤销保留审计，新增事项标记取消，课程追加反向变更；不能覆盖后续修改、提醒、进度、关联复习和个人计划。撤销重排只还原个人计划，保留现实安排。
4. “学期 → 管理标签”支持重命名与合并，先显示影响再确认。保留稳定 ID 与旧名称别名；旧名再次录入仍归入当前标签，历史关联去重，统计口径一致。
5. 客户端新增课程前后对比、考试复习联动说明、分组选择/动态冲突、撤销范围和保存结果。确认后刷新课程、事项、计划、提醒和统计。进度历史明确标记已撤销记录。
