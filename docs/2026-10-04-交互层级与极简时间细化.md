# 交互层级与极简时间细化

本轮按反馈减轻上下文操作的视觉重量、调整首页和剪贴板提示的留白、修正搜索图标位置，并细化学期周次过渡与时间滚轮。版本为 0.1.0+7，使用正式服务。

| 区域 | 本轮结果 |
| --- | --- |
| 上下文操作、首页、剪贴板 | 共用文字操作默认透明底、中性文字，按下时有轻反馈；页头导航去掉常驻外框，大字时使用紧凑图标。剪贴板提示以分隔线和文字融入页面，粘贴与关闭各有自己的操作空间。主操作、表单与内容容器按原用途保留层级。 |
| 搜索与字段图标 | 搜索图标距输入框外侧 12dp、距文字 8dp，图标在字段内垂直居中；共用字段统一前后图标几何。选择窗口的搜索复用同一字段。 |
| 学期周次 | 一个圆面在固定周次之间连续移动，白色数字随圆面位置保持对比。最新一周内容短滑入并淡入，文字不会和退出内容重叠。连续点选、减少动画与页面隐藏有对应处理。 |
| 时间选择 | 单个时间与起止时间直接使用小时、分钟滚轮；只留下标题、必要标签和确认操作。底部确认固定可见，长内容在其上方滚动；每周学习时段的结束端支持 24:00。 |

[截图与录屏对照页](../output/refinement-20261004/index.html)保留用户提供的修改前截图，区分 Flutter Widget 截图和安装包原生截图。Widget 数据为只读验证场景，用于核对控件布局与过渡。

## 验证范围

共用操作、字段几何、学期周次和时间选择的针对性检查已通过；完整 Flutter 静态检查无问题。Widget 证据覆盖普通手机宽度、320dp 大字和横屏；时间窗口另外核对了底部确认可见性。它们验证代表路径及共用控件，不说明所有设备和全部页面状态已被穷尽验证，也不作为帧率结论。

最终包在 Android 模拟器打开首页、学期、学校搜索和节次时间窗口。学期切到第6、第7周后恢复原第5周；节次滚轮向上滑动可推进小时，关闭后原时间完整保留，未保存设置。记录见 [week-check.json](../output/refinement-20261004/native/week-check.json)、[period-check.json](../output/refinement-20261004/native/period-check.json)，对照页包含原生截图和周次录屏。

首页切换日程/待办时日期与操作位置一致；学校搜索可筛选黑大，清空后恢复两所学校。当前进程日志未发现崩溃、布局溢出或插件注册异常。走查后恢复原首页模式和周次，无生产记录保存、导入或删除。汇总见 [final-delivery-check.json](../output/refinement-20261004/native/final-delivery-check.json)。
