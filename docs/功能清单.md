# 拾日功能清单与实现位置

版本 1.1.1 / Android 构建 12，2026-10-17。

这篇是给改代码的人用的：想知道某个功能落在哪，来这里查。用法说明在[完整使用说明](产品规则.md)，HTTP 路由在[接口索引](接口索引.md)。

客户端的路径从 `apps/mobile/lib` 起算，服务端从 `services/api/app` 起算。页面入口统一在 `app/semester_app.dart`，路由表也在那儿。

## 账号与数据

注册、登录、恢复码、改密码都在 `features/accounts/auth_page.dart`，后端是 `auth.py`。登录态刷新和弱网重试在 `core/api.dart`，刷新请求带一个标识，重试时用它去重。首次引导和“再看一次说明”在 `ui/empty_states.dart` 和 `app/semester_app.dart`。资料与学习偏好在 `features/profile/` 对 `user_profiles.py`。

导出和注销是 `accounts/personal_data_page.dart` 配 `personal_data.py`：导出走系统文件选择器存 JSON，注销要密码加一句确认文字。反馈在 `FeedbackPage`，落库和读取都在 `personal_data.py`，开发者用 `scripts/view_feedback.py` 看。退出登录不只是删 token，`app/controller.dart` 会把本机账号缓存、学校登录状态、提醒和桌面卡片一起清掉，漏一个就会在换账号后串数据。

## 学期与课表

学期的新建、切换、改名、删除在 `features/semester/` 和 `semester_management.py`，删除前先查关联数量。周次和节次在 `period_editor.dart`、`academics.py`，第一周周一和总周数这两个值几乎被后面所有时间计算引用，改之前先搜一遍。

学校搜索和教务登录是 `features/import/school_adapters.dart`、`school_browser.dart`，实际读取靠 `assets/*_reader.js`，解析在 `features/import/*_parser.dart`，入库和重复导入检查在 `academics.py`。河南工大的 10 节作息由 `school_adapters.dart` 带出来，跟课程一起在 `academics.py` 落盘。手录课程在 `features/import/manual_page.dart` 和 `course_management.py`。

调课、停课、请假、恢复这一组在 `features/changes/`，后端 `changes.py` 和 `course_participation.py`。这里的原则是只动指定的那一次课，整门课不受影响。

## 日程与今日

今日页是 `features/home/today_dashboard.dart` 加 `today_view_enhanced.dart`，首页放什么、什么顺序在 `home_preferences.dart`。周课表在 `features/calendar/schedule_grid.dart` 和 `calendar_week_pager.dart`，按天看的列表与详情在 `calendar_panel.dart`、`day_context_panel.dart`。

手动加日程在 `event_form.dart`，后端 `calendar_events.py`。时间说不全这件事散在三处：`notice_fields.dart` 管输入，`item_schemas.py` 管校验，`notice_event_time.py` 管落地——开始点、日期、周次、窗口、全天、未知、到场时间都在这里定义，改一种精度要三处一起看。

冲突核对在 `event_conflict_review.dart`、`fixed_conflict_guard.py`、`agent_attendance.py`。注意它只处理这次新产生的冲突，历史重叠不会被翻出来重算。空档查询和建议在 `features/home/study_opportunity_card.dart`，算法侧是 `briefs.py` 和 `capacity.py`。

## 任务与学习

任务、作业、考试的记录、编辑、完成、取消、恢复、详情、历史都在 `features/items/` 和 `items.py`。列表排序和批量操作在 `items_view.dart`、`item_actions.dart`，可用的动作由当前状态决定，另一半校验在 `agent_tools.py` 里。考试页和关联课程是 `features/centers/exam_pages.dart`、`exam_planning.py`。

学习时段在 `features/planning/availability_page.dart`，批量选中星期后的合并或替换在 `availability_bulk_sheet.dart`，计算在 `planning.py`。休息和前后缓冲同样进 `capacity.py`，但它们只影响可学习的时间，不会去改日程本身的事实。

估时、可拆分、等待条件、最早开始时刻在 `schedule_setup_actions.dart` 和 `task_readiness.py`。方案生成从 `schedule_page.dart` 进，预览页是 `proposal_page.dart`，求解在 `scheduler.py`，落库和版本校验在 `schedule_api.py`。固定、取消、重排在 `plan_list.dart`、`plan_change_confirmation.dart` 和 `replanner.py`。学习进度在 `progress_page.dart`，仍然走 `schedule_api.py`。任务时间评估在 `features/planning/risk_widgets.dart`，算法是 `capacity.py`。

## 助手与通知

智能修改中心在 `features/operations/operation_page.dart` 和 `operations.py`：原通知时间、文字或媒体要求、前后核对、编辑确认都在这一条链上。

文字助手在 `features/agent/`，后端是 `agent_api.py`（HTTP 与会话）、`agent_runtime.py`（LangGraph 主循环）、`agent_tools.py`（工具表，每个工具的说明就是行为规约）。截图识别在 `features/media/`、`media.py`、`media_recognition.py`；录音在 `hold_voice_button.dart`、`media_input.dart`，转写同样归 `media_recognition.py`。系统分享和剪贴板在 `incoming_notice_draft.dart`、`clipboard_notice_prompt.dart`，加上 Android 侧的分享接入——剪贴板只在本机判断，发不发由用户决定。

对话历史在 `agent_controller.dart`，接口在 `agent_api.py`。预览的字段对照和多选在 `preview_quick_edit.dart`、`preview_editing.py`。保存后的核实、重试和“已保存待同步”在 `decision_journal.dart`、`items_controller.dart`。撤销在 `agent_receipt.dart`、`agent_undo.py`、`operations.py`，撤之前会查当前版本，恢复旧内容要是会造成新冲突就拒绝。

来源管理在 `features/media/source_view.dart`、`media.py`、`media_jobs.py`：看原文、看附件、修识别文字、重试、删文件。

## 标签

标签推荐和分类在 `features/tags/tag_intelligence.dart` 与 `tag_classifier.py`，规则数据在 `services/api/app/data/tag_rules.json`。同类标签自动合并在 `tag_management_page.dart`，后端 `taxonomy.py`；旧名称和旧 ID 到新标签的映射落在 `event_store.py`，历史统计靠它才对得上。点标签看关联记录是 `tag_records_page.dart`。手动重命名和合并在 `tag_management_page.dart` 的“更多”里，动手前先出影响预览。

## 查找与统计

全文搜索在 `features/search/search_page.dart`，后端是 `personal_data.py`，查标题、地点、备注和通知原文。统计在 `features/insights/` 和 `insights.py`，页面上的“已排时长”“去重占用”“实际进度”是三个不同的数，别在接口层合并。

## 提醒与系统入口

提醒的编辑和同步在 `reminder_editor.dart`、`reminder_sync.dart`，规则在 `reminder_rules.py`。离线延后和“标记完成”在 `items_controller.dart`、`android_notifications.dart`——延后可以纯本机做，完成必须服务端确认。静默时段、已设置清单、测试通知在 `reminder_settings.dart`、`device_surfaces_page.dart`。

桌面日程卡和快速记录在 `core/device_surfaces.dart`，原生那半是 `DeviceSurfaces.kt` 里的 `ScheduleWidget`。进行中实时通知也在 `DeviceSurfaces.kt`，倒计时、停止、到时撤下都在原生侧。动效、读屏、大字号、键盘避让这些散在 `ui/`、`ui/v2/` 和 `features/timetable/shell_page.dart`。

## 标签整理规则

同类标签统一到一个常用名字，比如会议、排练、讲座、实验作业、运动。该分开的仍然分开：Python 与 Java、面试与笔试、排练与演出。整理不改标题、原文和时间；旧标签 ID 和旧名字继续能解析到保留的那个标签，历史统计跟着换归属。

规则在 `services/api/app/data/tag_rules.json`，移动端那份副本由 `scripts/generate-tag-rules.py` 生成，两边词表必须一致，测试里有专门的检查。标签整理和通知理解是两码事：前者纯规则，后者才按配置调模型。

## 当前范围

交付平台是 Android，增强通知长什么样由系统定。学校适配器两所。学习进度靠用户自己记。还没做的是：个人耗时学习、自动每日复盘、团队协同、反馈工单回复、App 内的深色模式切换。细节见使用说明对应章节。
