# 内部界面补齐与逐页覆盖

日期：2026-09-27。

## 对上一轮结论的纠正

上一轮主要重做四个主页、导航、统计和助手，并改变共用主题。大量内部页面只是继承主题，没有单独整理信息与操作结构。将其描述为“整体UI重做”覆盖不足；测试通过只说明被测行为与布局未发现相应问题，不能证明设计完成度。

本轮以实际路由和页面类为清单，重新设计详情、编辑、来源文稿、规划方案、设置和导入各自的内容结构；延续用户已经选择的明快蓝绿方向，减少重复的大眉题和横幅。

## 已实施

| 页面组 | 实际变化 |
|---|---|
| 事项/日程详情 | 记录名称与状态、时间地点事实、进度与主要操作、提醒、来源与历史分层；不再复用列表卡当详情页 |
| 事项/日程编辑 | 内容、时间、工作量、提醒分组；核心工作量移出折叠；固定保存区与可见错误，保留未知时间和原校验 |
| 提醒 | 提前提醒/指定时刻含义清楚，预设有选中态；考试14天/7天提醒保持，模式切换不丢数据 |
| 课程/考试 | 课程事实、相关任务、考试和历史分开；考试事实与复习工作区分离，安排覆盖不冒充完成进度 |
| 调课/考试改期 | 通知依据、目标、新安排、影响与确认分层；响应式旧/新对比、固定冲突确认与个人重排门槛保留 |
| 学习时间/规划 | 按星期编辑可用时段，方案用时间轨道，剩余工作与实际投入分开，风险按时间扣除展示 |
| 账号/建立学期 | 登录/注册/恢复有明确状态；学期校历与每天节次分组，节次可点选，批量文本编辑是次级入口 |
| 课表导入 | 选择学校/教务登录/核对课表流程提示；手工课程按身份与时间分组，确认动作位置稳定 |
| 图片/语音/原文 | 来源操作区、识别文稿和后续动作分开；语音区显示实际录制状态，原文与确认稿采用文稿阅读布局 |
| 自然语言修改 | 已生成预览时输入区收起，保留“修改这次要求”，确认保存成为主动作，避免重复原文和两个主按钮竞争 |
| 学期/标签管理 | 功能文案替换旧宣传式句子；标签影响按事项、日程、计划、历史进度分别列出，确认协议不变 |

## 实际发现并修复的问题

- 新分组的背景遮住ListTile点击反馈：改由Material承载背景。
- 固定保存区暴露离屏字段校验/错误反馈缺口：直接校验模型值，并在操作区显示错误，不仅依赖当前挂载字段。
- 展开设置后浮动标签顶部裁切：增加展开区顶部空间。
- 大字号用户名规则省略、规划目标输入说明缺失：允许换行并将说明分离到helper。
- 大字号时间选择器AM/PM裁字及24小时表盘密集：节次采用24小时制，大字号直接使用小时/分钟输入。
- 长按钮出现单字孤行、文字贴边：精简改期按钮，增加确认按钮留白并居中，保留完整确认含义。
- 禁用勾选使必须核对的锁定计划信息过淡：文本单独保持可读颜色。
- 大字号流程箭头与下一步分离：作为同一换行单元。
- 旧测试依赖旧字段位置或滚动后未等待布局：更新定位和等待，保留提交次数、来源、版本、冲突与明确确认断言。
