## 实际界面变化

- **今日**：日期与周次压缩，下一安排集中显示时间/名称/地点；课程和活动按彩色时间轨道展示；紧急截止单独提醒。保留自定义模块。
- **日程**：月周工具栏、日周分段、选日/今天高亮；网格使用稳定课程色，日视图显示完整内容，截止独立。跨时区排序按真实时刻计算。
- **计划**：个人时间安排与任务清单分层；截止、预计剩余、余量直接展示；保留安排、进度、完成、锁定和历史入口。
- **学期**：当前周、紧凑可滚动周带、带日期/类型的节点；次级工具集中，统计不重复放到各页。
- **统计**：主要占用时长、小计、实际记录形成层次，蓝/青堆叠图与图例一致；大字号使用可点击的分类文字列表。真实用时未填写仍为“未记录”。
- **助手/二级页面**：主字段两列核对、大字号纵向；减少重复横幅，统一蓝绿主题；输入区与导航更紧凑，横屏键盘时收起次要说明。分组、冲突、撤销、来源和草稿流程保留。
- **动效**：点击反馈、页切换、选周、内容展开和图表随操作变化；减少动画设置直接显示终态。页切换保留原State和滚动状态，隐藏/后台取消计时。
- **品牌资产**：保留拾日名称和图标构形，将原生矢量配色与启动图标同步为蓝绿系统，已重新导出各密度PNG。
