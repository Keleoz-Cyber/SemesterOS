# 拾日接口索引

版本1.1.1，2026-10-17。下表由当前Python路由源码整理，开发者可点击实现查看请求模型、响应字段和业务检查。服务根地址的 `/health` 返回服务及数据库状态；业务接口统一位于 `/api/v1`。认证、归属和权限以对应实现为准。

交互式接口定义由服务端 `/docs` 和 `/openapi.json` 提供。日期、版本、重复请求、预览确认、错误和事务规则见[后端说明](技术契约.md)。表中含辅助接口，用户入口见[功能清单](功能清单.md)。
