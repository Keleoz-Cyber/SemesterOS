# 拾日接口索引

版本 1.1.1，2026-10-17。

这份表是对着 `services/api/app` 的路由源码一条条核出来的，共 112 条（含 `/health`）。点实现那一列能跳到处理函数，参数、响应字段、业务检查都在函数里。

路径怎么拼：业务接口统一挂在 `/api/v1` 下。有两个模块自己带了前缀——`agent_api.py` 和 `agent_media.py` 带 `/agent`，所以实际是 `/api/v1/agent/threads` 这种；`user_profiles.py` 带 `/me`，实际是 `/api/v1/me/profile`。1.1.1 这次把表里这三组漏掉的前缀补上了，以前照着旧表拼路径会 404。

要看得更细，跑起服务打开 `/docs` 或 `/openapi.json`。日期怎么存、重复请求怎么去重、预览为什么要确认、错误码什么含义、事务边界在哪，这些在[开发说明](技术契约.md)里。用户从哪个页面进到哪个接口，看[功能清单](功能清单.md)。
