## 组件迁移

- `app_controls.dart`集中提供Forui按钮、图标按钮、输入/表单、勾选、开关、列表项、折叠、筛选标签与确认框。
- 底部导航使用真实`FBottomNavigationBar`，分段选择使用真实`FTabs`；不再只替换自绘切换栏的触摸层。
- `AppFormField`保留`FormFieldState<String>`和外部控制器，兼容原有GlobalKey、校验与重置。
- 选择字段去掉Material浮动标签外观，与Forui输入标签对齐；仍用已有弹层支持长列表搜索及显式清空。
- UI静态扫描：常见Material控件直接构造在适配层外为0，记录于`output/ui-control-audit.json`。样式工厂不是控件实例。
- 明确保留：MaterialApp/Scaffold等基础布局、按统一主题呈现的原生日期时间选择器、加载/业务网格/图表绘制，以及学校拥有的WebView内容。不是声称底层零Material。

## 配色

- 页面底色`#F5F7FB`，卡片白色，主文字`#24344D`，次文字`#5F6F84`。
- 普通操作统一蓝色`#3D66C1`；辅助青绿`#34766F`只在相关数据与少量辅助信息使用。
- 主色浅底`#EEF3FC`、青绿浅底`#EDF5F2`。普通空状态不使用大面积彩色背景。
- 课程色块采用同组低饱和度颜色；告警/错误只在相关状态使用。
- 清理页面中重复且不一致的硬编码颜色，启动图标同步重导出。
- 七个核心文字组合的对比度为4.71—12.55；白字/主蓝5.43。具体值见`output/unified-color-contrast.json`。这不等同整App无障碍认证。
