## 开发者查看反馈

用户从“账户 → 反馈问题”提交后，内容保存在服务端 `user_feedback`。在已配置服务器SSH的维护电脑执行：

```powershell
python scripts/view_feedback.py
python scripts/view_feedback.py --limit 100 --category reminder --no-open
```

工具只读查询，默认最近50条，输出 `output/feedback/latest.html`。页面列出时间、账号、类别、描述、期望和App版本；再次运行才刷新。普通用户没有查看其他账号反馈的接口。

用户提供的文字意见另在[试用与问题记录](试用与问题记录.md)整理，不能与服务器反馈数量或独立试验结果混为一谈。
