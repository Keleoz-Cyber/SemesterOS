## 当前对话内完成录入

录音 → 当前对话显示识别状态 → 文字进入同一个输入框 → 修改后发送。识别失败在原地重新录音、重试或改用文字。

图片选择后也在原对话识别与编辑。旧/capture与/capture/media入口转向统一助手；旧独立组件保留兼容测试，不再由助手自动打开。

识别本身不创建事项，也不等于用户已确认。发送时才保存核对后的文字/来源版本，随后保留原有AI修改预览及明确保存。

## 状态与恢复

- 临时录音先复制到当前账号的本机草稿目录，录音器释放临时文件后仍可重试。
- 上传请求重试复用标识；来源确认响应丢失时核对服务器版本，避免重复PATCH导致发送标识变化。
- 来源草稿按学期和对话草稿隔离，切换账号、取消或销毁后的迟到响应不再写回。
- 新旧来源、用户编辑、草稿恢复与会话切换需要单独测试，避免简化界面时丢失内容。
