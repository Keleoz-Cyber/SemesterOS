# 拾日：明快时间面板 UI 重设计

用户于2026-09-27明确选择“明快的时间面板：蓝绿主色，醒目的时间轴与彩色课程块，动效跟随操作”。本次授权大改实际Flutter UI，保留业务流程与数据语义，不以再次做营销式原型替代实现。

## 设计判断

这是面向大学生日常使用的原生Android日程工具。主视觉来自时间、课程、通知变化和真实统计。页面必须首先回答“接下来做什么、在哪、是否冲突”，文案使用明确名称、时刻与动作。

考虑过校园手帐和高对比数字日历；前者强化纸张隐喻、会牺牲网格密度，后者容易压过彩色课程辨认。采用用户选择的明快时间面板，保留青春感，同时加强时间阅读与操作反馈。

## 共用视觉规则

- 浅灰蓝背景 `#F3F6F8`，白色主要内容面，主字 `#162B40`、次字 `#53687D`，主蓝 `#175CD3`，青绿 `#087F8C`。蓝色表示操作，绿/蓝/橙/紫是课程或内容识别色，危险单用红色，不混淆分类和紧急程度。
- 采用4/8dp间距；页面边距20（小屏16）；组间24；内容内16。主要内容容器20圆角，次级容器12，标签8，胶囊仅用于分段选择。避免所有东西都包成大白卡。
- 正文16sp，辅助14sp，元信息12sp；页面标题26/28，时间数字可34；正文默认常规，中等字重用于事项，粗体只用于当前重点。数字使用等宽数字特性，中文跟随系统无衬线。
- Android点击区至少48dp，图标统一Material rounded/outlined一套语义：导航未选outline、已选filled；每页一个主要动作。不通过纯颜色表达类型或风险。
- 本轮主视觉是亮色；不宣称已有完整暗色主题。保留系统字号，不用硬裁剪和textScale限制逃避适配。

## 页面结构

1. **今日**：小型日期/周次栏；下一项占主要视觉，醒目时间与地点；全天使用时间轨道和色块辨认课程/活动；截止事项单独标记截止语义。保留可排序/隐藏模块与真实建议，不堆总数卡、不让装饰挡住第三条课。
2. **日程**：紧凑月/周栏、日/周分段；选中日期统一；周网格突出今天、当前时刻和不同课程，按天视图采用时间轨道而非复制首页。转场保留选日和滚动。冲突必须可读，不把截止当占用。
3. **计划**：待办与个人时间安排形成清晰两层；任务名称/截止/剩余/余量是主要信息。主操作“安排任务”；学习时间只有一个编辑入口。保留完成、进度、锁定、重排和历史，不堆算法按钮。
4. **学期**：当前周数字与可滚动周带；关键考试/事项形成带类型标记的时间轴；课程事务、考试、标签、管理收进整齐的次级区域，统计仅在这里保留主入口。
5. **统计**：重点数字与占用分布形成清晰图形层级，日期/类别/标签筛选就地变化；点图查看来源；实际用时未记录仍显示未记录，不能用0或计划冒充实际。
6. **助手与详情**：输入与图/语音保持同一入口；确认卡突出改动内容和明确按钮，参考资料折叠。延续分组选择、冲突核对、撤销与来源。普通表单和二级页服从全局主题，取消宣传式大标题与装饰。

## 动效

- 点击反馈100–140ms；选中和页内状态180–240ms；抽屉/展开260–320ms；图表350ms以内。
- 页签切换淡入与轻位移，不重建页面状态；周切换保留方向；任务完成反馈与结果展开有明确终点。
- 不做永久浮动、装饰转圈、自动轮播或滚动劫持。减少动画设置下使用静态终态；隐藏页不持续跑动画。
