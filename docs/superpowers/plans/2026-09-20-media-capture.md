# 图片通知与语音记录实施计划

目标：选图/录音 → 按账号隔离保存来源 → 本地OCR/ASR识别 → 对照来源修正文稿 → DeepSeek结构化核对 → 用户确认。支持失败重试、取消和重启恢复。

- [x] 验证RapidOCR与SenseVoice本地运行，锁定依赖和模型获取方式，不新增商用密钥。
- [x] 来源、识别作业与归属测试先行：大小/格式/时长、EXIF去除、跨账号拒绝、取消后迟到结果、租约恢复、重复上传与解析版本。
- [x] 来源表与迁移、私有文件存储、数据库作业状态与独立worker、内容读取/删除、文字解析和事项来源追溯。
- [x] Flutter选图、限时录音与回放、识别状态、修正文稿、手工兜底、按账号保存本地草稿与退出清理。
- [x] 真OCR/ASR合成联调、真实模型解析、Flutter与后端回归、Android构建、只读审查、文档和分支交付。

默认OCR/ASR在服务端本地CPU运行，原媒体不发给DeepSeek；仅用户确认发起结构化解析时发送核对文字及课程候选。图片单张10MB，JPEG/PNG/WebP，限制像素；语音先采用App录制16kHz单声道PCM WAV，最多120秒/20MB。长期作业通过数据库排队与租约恢复，取消只取消未完成识别/解析，不删除正式事项。模型文件与用户媒体不入Git。
