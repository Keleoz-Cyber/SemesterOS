# 拾日文档

拾日（SemesterOS）是面向大学生的智能日程助手。本目录只保留当前规则、运行方法、验收要求和一份发行记录；旧方案、重复阶段报告及构建中间记录由 Git 历史追溯。

| 文档 | 内容 |
| --- | --- |
| [产品规则](产品规则.md) | 页面分工、通知理解、时间与个人请假、确认和撤销、已知范围 |
| [技术契约](技术契约.md) | 事实模型、账号隔离、Agent、并发与幂等、容量和排程、提醒 |
| [学校与媒体接入](学校与媒体接入.md) | 河南工大与黑大读取范围、重导入、图片与语音、来源和草稿 |
| [测试与比赛说明](测试与比赛说明.md) | 回归矩阵、设备验收、实验口径、赛事材料与匿名要求 |
| [部署与维护](部署与维护.md) | 本地运行、云端发布、备份恢复、Android 构建、GitHub 发行 |
| [交付说明](交付说明.md) | 本次版本、唯一 APK、实际验证结果、发布状态及验证边界 |
| [原始比赛规则 PDF](2026AIC算法创新赛赛题规则汇总260506-1.pdf) | 用户提供的原始规则；材料要求保留其核验日期和页码 |
