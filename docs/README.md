# 拾日文档目录

适用版本 **1.1.1（Android 构建号 12）**，最后整理 2026-10-17。

文档有点多，先说怎么读：想用这个 App，只看[完整使用说明](产品规则.md)；想改代码，先看[后端开发说明](技术契约.md)，再拿[接口索引](接口索引.md)当字典查；要部署，直接跳[部署与维护](部署与维护.md)。比赛规则和历史验证记录在最后一段。

## 给用户看的

- [项目介绍](../README.md)：这是什么、装哪个包、怎么把源码跑起来、目录怎么分。
- [完整使用说明](产品规则.md)：每个入口怎么用，时间说不全时怎么记，冲突怎么核对，学习安排怎么存和撤。写得最细的一篇。
- [功能清单](功能清单.md)：谁对应哪个文件。排查“这功能在哪实现”时用，不是给用户读的。
- [学校与媒体接入](学校与媒体接入.md)：河南工大和黑大两套导入的差别、作息怎么预填、图片和录音走哪条链路。
- [版本与交付说明](交付说明.md)：1.1.1 里有什么、APK 在哪、校验值、哪些验证做过。
- [完善记录](本轮完善进度.md)：这一版和之前几版改了什么，按日期列。
- [试用与反馈](试用与问题记录.md)：别人试用时提的意见，以及开发者怎么把反馈捞出来看。

## 给开发和维护看的

- [后端开发说明](技术契约.md)：数据归属、时间表示、冲突判定、助手边界、事务和版本号。改后端前必读。
- [接口索引](接口索引.md)：按路由源码整理的方法、路径、所在文件。查接口用，别从头读。
- [移动端开发说明](../apps/mobile/README.md)：Flutter 环境、真机调试、目录、Android 系统接入、发布流程。
- [部署与维护](部署与维护.md)：本地起服务、云端部署、模型文件下载、APK 构建、备份和反馈工具。
- [测试与比赛说明](测试与比赛说明.md)：怎么跑测试、哪些范围验收过、提交要什么、数据从哪来。
- [界面维护规则](../design-system/shiri/MASTER.md)：交互约定、未知时间怎么显示、保存后怎么反馈、动效和无障碍。
- [晴日界面说明](../design-system/shiri-v2/DESIGN.md)：v2 版的布局、配色、组件和动效落点。
