## 服务器布局与查看

项目在 `/opt/semesteros`，`current` 是指向 `releases/` 的受管理软链接；私有配置是根目录 `.env`，权限 600。模型在 `models/`，以只读方式挂载；备份在 `backups/`。

`deploy/compose.cloud.yaml` 使用独立 `semesteros-cloud` 项目与数据库 / 媒体卷。API 只监听服务器回环地址 8871，数据库不映射宿主端口；API 和识别 worker 使用非 root 用户。模型、数据库和媒体共同构成服务持久化状态。

```bash
ssh keleoz-tencent
cd /opt/semesteros/current
sudo docker compose --env-file /opt/semesteros/.env -f deploy/compose.cloud.yaml ps
sudo docker compose --env-file /opt/semesteros/.env -f deploy/compose.cloud.yaml logs --tail=100 api worker
```

独立 Nginx 站点将子域名代理到 API，模板为 `deploy/nginx-semesteros-subdomain.conf`。已有博客使用原端口 8080；旧路径片段保留 410 响应，避免 API 请求落入博客。HTTP 除 ACME 验证外跳转 HTTPS；API 响应使用 private/no-store，私有配置、媒体与 APK 不暴露为下载目录。

## 备份与发布

手动备份：

```bash
sudo bash /opt/semesteros/current/deploy/backup_cloud.sh
```

脚本短暂停止本项目 API / worker，备份 PostgreSQL、私有媒体和配置，完成后恢复原容器。备份含私人数据与密钥，目录权限 700、文件使用 077 掩码，不上传公共下载位置。尚未完成自动备份、跨服务器灾备和完整恢复演练。

将已检查源码放入一个新的 `/opt/semesteros/releases/` 目录，使用唯一镜像标签。发布前确认容器内应用和 Alembic 配置可由运行用户读取、迁移可用，并核对数据迁移兼容性。服务器执行示例；将 `reviewed-release` 替换为实际审核目录名：

```bash
release_name=reviewed-release
sudo python3 "/opt/semesteros/releases/$release_name/deploy/deploy_cloud.py" \
  --release "/opt/semesteros/releases/$release_name" --tag "$release_name"
```

`deploy_cloud.py` 先构建镜像，再备份数据库 / 媒体 / 配置，执行增量迁移，启动 API 与 worker，通过本机健康检查后切换 `current`。失败恢复旧配置和旧镜像；迁移后的新增表不自动退回，应用回退须核对数据库兼容性。保留发布回执、备份校验和旧 release，另做公网鉴权与实际业务验证。不要执行 `down -v` 删除数据卷，也不要为回滚清空数据库或媒体。

子域名配置工具 `deploy/migrate_subdomain.py` 保留 `prepare-http`、`enable-https`、`retire-old` 三阶段，分别备份并校验配置；已有 HTTPS 不得用准备阶段降级。首次证书签发在准备好 HTTP / ACME 目录后执行：

```bash
sudo certbot certonly --webroot -w /var/www/semesteros-acme \
  -d semesteros.keleoz.com --cert-name semesteros.keleoz.com \
  --non-interactive --deploy-hook 'systemctl reload nginx'
```

Certbot 使用独立证书与自动续期。恢复旧入口时只选明确核对过的 `domain-retire-old-*` 备份，将原片段恢复到 `/etc/nginx/snippets/semesteros-location.conf`，`nginx -t` 通过后 reload；不需要恢复数据库或关闭新子域名。

## 构建手机包

在仓库根目录的 PowerShell 执行，先完成针对当前源码的检查：

```powershell
. .\scripts\android-device.ps1
Set-SemesterGradleJava
Set-Location apps/mobile
flutter --no-version-check pub get
flutter --no-version-check build apk --release --no-pub --target-platform android-arm,android-arm64,android-x64 --dart-define=API_BASE_URL=https://semesteros.keleoz.com --target lib/main.dart
```

构建默认输出为 `apps/mobile/build/app/outputs/flutter-apk/app-release.apk`。交付前检查版本、包名、原签名、API 地址、通知图标、学校读取资源与网络范围、ABI 及 16KB 对齐，计算 SHA-256 并记录源快照；核对后再替换唯一 `output/apk/拾日-0.1.0-手机测试.apk`。覆盖安装保留已有数据，卸载会清除本机登录与缓存。

debug / Profile 采样、组件截图和模拟器操作各有验证范围，不能替代手机 WebView 导入、有效语音准确率、厂商后台提醒和实际手机性能。单独的 QA 构建不得交付为正常用户包。
