# 云端手机测试部署

2026-09-20首次部署于SSH主机`keleoz-tencent`，使用空云端数据库。2026-09-21按用户要求切换为独立子域名`semesteros.keleoz.com`，保留该云端数据库与所有已有数据；旧路径入口已停用。

## 手机使用

- 手机测试包：本地`output/apk/SemesterOS-0.1.0-subdomain-phone-debug.apk`，通过USB或局域网传输，不放到网站下载。支持ARM64和ARM32，Android 7或以上；当前为调试签名测试包，不是商店发布包。
- API入口：`https://semesteros.keleoz.com`，健康检查为`/health`。原`https://keleoz.com/semesteros`及其API、APK子路径返回410。
- 已有云端账号继续使用，无需因域名变更重新注册；新用户自行注册。密码支持8—128位，注册、登录与恢复校验一致。恢复码请自行保存。
- 未迁移电脑上的任何私人账号、课表、事项或原图录音。验证使用独立合成账号；新注册账号没有预置学期。
- 手机不需要和电脑处于同一网络，电脑关机后云端服务仍可使用。

## 服务器布局

独立项目：`/opt/semesteros`。当前源码在`releases/phone-test-20260920`，`current`指向该目录。私有配置为`.env`（600权限），模型在`models`（容器只读），备份在`backups`。

`deploy/compose.cloud.yaml`创建`semesteros-cloud`项目，数据库和媒体分别使用独立命名卷。API只在服务器回环地址8871提供服务，数据库不映射宿主端口。API、识别worker和数据库配置自动重启及资源限制；API与worker用非root用户运行。

已有博客继续运行在原端口8080。新Nginx站点是`/etc/nginx/sites-available/semesteros`，通过同名sites-enabled软链接启用；源码模板为`deploy/nginx-semesteros-subdomain.conf`。新域名直接代理到API，路径不再包含`/semesteros`。旧片段`/etc/nginx/snippets/semesteros-location.conf`保留为410响应，避免旧API请求落入博客根路由。API响应设置private/no-store；模型密钥不进入APK或Git。

DNS在`keleoz.com`主域名解析区配置`semesteros A 111.229.129.241`。HTTPS使用独立Let's Encrypt证书，首次签发有效期至2026-12-20，Certbot定时续期及续期后的Nginx reload已配置。HTTP仅放行ACME验证，其余请求跳转HTTPS；不复用主站的域名证书。

## 查看和更新

```bash
ssh keleoz-tencent
cd /opt/semesteros/current
sudo docker compose --env-file /opt/semesteros/.env -f deploy/compose.cloud.yaml ps
sudo docker compose --env-file /opt/semesteros/.env -f deploy/compose.cloud.yaml logs --tail=100 api worker
```

更新前先备份，并将新源码放入新的`releases`目录。构建新的镜像标签，执行迁移后启动API和worker，通过健康与业务检查后再切换`current`。不使用`down -v`，它会删除云端数据卷。版本回退需要保留旧镜像，并确认数据库迁移是否向后兼容；首次上线前的Nginx备份位于`backups/nginx-keleoz-*.conf`。

## 手动备份

```bash
sudo bash /opt/semesteros/current/deploy/backup_cloud.sh
```

脚本短暂停止本项目的API和worker，备份数据库、媒体和私有配置，结束时恢复服务，不停止博客。备份含私人数据和密钥，目录权限700，文件按077掩码创建，不发布到下载路径。尚未设置自动备份或跨服务器灾备。

## 构建手机包

在仓库`apps/mobile`目录执行（PowerShell）：

```powershell
. '..\..\scripts\android-device.ps1'
Set-SemesterGradleJava
flutter --no-version-check build apk --debug --no-pub --target-platform android-arm,android-arm64 --dart-define=API_BASE_URL=https://semesteros.keleoz.com --target lib/main.dart
```

本地交付文件为`output/apk/SemesterOS-0.1.0-subdomain-phone-debug.apk`，校验信息在同目录JSON。与旧的模拟器本机后端包、旧路径云端包分开保存。建议直接覆盖安装，避免卸载清除本机登录与缓存；实际手机安装尚未验证。

模拟器已启动时，在同一目录连接新云端：

```powershell
flutter run -d emulator-5554 --dart-define=API_BASE_URL=https://semesteros.keleoz.com
```

`scripts/dev.ps1 -Action Android`仍默认连接电脑本地后端，没有被此次域名迁移改成云端。

## 子域名迁移与回退

已完成顺序：在DNSPod主域名区域新增A记录，部署独立HTTP站点供证书验证，签发证书，启用HTTPS，验证跨入口账号／会话，再停用旧入口。整个过程没有重启业务容器或迁移数据库。

迁移入口为`deploy/migrate_subdomain.py`，支持`prepare-http`、`enable-https`、`retire-old`三个明确阶段，不能用`prepare-http`将已有HTTPS降级。`deploy/install_nginx_path.py`已停用，避免再次安装旧路径。配置修改前分别备份到`/opt/semesteros/backups/domain-<阶段>-<时间>/`；Nginx检查或TLS就绪验证失败会恢复该阶段旧配置。TLS验证使用有界重试等待新worker就绪，始终校验证书。

独立证书签发命令（服务器执行，首次准备HTTP后）：

```bash
sudo certbot certonly --webroot -w /var/www/semesteros-acme -d semesteros.keleoz.com --cert-name semesteros.keleoz.com --non-interactive --deploy-hook 'systemctl reload nginx'
```

如需恢复旧入口，从`domain-retire-old-*`对应的备份恢复`nginx-semesteros-location.conf`至`/etc/nginx/snippets/semesteros-location.conf`，执行`sudo nginx -t`通过后再reload。恢复旧入口不需要恢复数据库，也不需要停止新子域名。不要自动选取未经核对的备份文件。
