# 面向学生的交互重构

2026-09-27。用户再次指出：此前的修改保留了过多内部流程、默认控件、等权重操作和提示文字。此轮按用户任务调整交互，而非只替换颜色。

## 已改造的页面与规则

| 页面族 | 调整 |
| --- | --- |
| 今日、日程、课表、计划、学期 | 列表状态、时间范围和模式采用统一滑动切换条；周次使用选中卡片；日程筛选改底部面板；大字标题与操作分行 |
| 统计 | 周期/图表模式统一；分类与标签集中到筛选面板，取消不提交、应用一次请求，只展示生效条件 |
| 助手、图片、语音、文字记录 | 同一输入区切换键盘和按住说话；松开完成、上滑取消；识别结果可编辑后发送；原消息时间/重试/手动输入/上传记录收进菜单；去掉日常录入步骤条 |
| 事项、日程详情 | 编辑进顶栏，低频动作进底部菜单；完成为单一主要动作；进度和提醒是可点击信息行，原通知默认折叠 |
| 事项、日程、考试编辑 | 字段选择统一为可搜索底部面板；保留未知时间，不默认填结束时间；更多设置折叠，去掉重复提示和入口 |
| 课程、考试、改期 | 多个并列添加按钮合并为添加菜单；简化复习操作与改期说明；前后差异和重要冲突确认保留 |
| 进度、可学习时间、计划方案 | 删除重复步骤说明、精简工作量措辞；数值及实际用时含义保留；保存前影响确认保留 |
| 登录、学期设置、导入、标签、智能修改 | 统一切换/选择控件；简化说明、消息时间和历史按需展开；教务网页本身由学校提供 |

shared组件：AppSegmentedControl、AppPickerField、RecordMenuButton/RecordActionTile、HoldVoiceButton。没有引入无关动画包或额外模型服务。

## 重要行为

- 麦克风只由按下触发。权限返回前松手、上滑/指针取消、切到后台、账号变更或页面销毁均不会继续迟到录音或上传取消内容。
- 临时录音保留到接收方复制/处理结束，再清理。真实识别服务未被假结果代替。
- 切换文字/语音保留草稿；图像识别、原始来源、原消息时间、手动兜底仍可访问。
- 改期、计划保存、完成、取消仍保留实际影响确认和版本校验。简化界面没有把预览直接写成已保存。
- 信息不足的风险显示具体原因，不再同时突出正余量和模糊警告；无结果的风险卡隐藏。
