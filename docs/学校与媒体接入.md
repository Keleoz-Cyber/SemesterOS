# 学校与媒体接入

更新：2026-10-09。本文保留接入方式与已观察到的范围；当次发行是否重新验证，见[交付说明](交付说明.md)。真实校方认证、匿名解析、导入预览和确认保存是不同证据。

## 学校读取边界

用户先登录拾日，选择学校与目标学期，在学校原始网页自行完成认证，再打开本人课表读取。教务密码、Cookie、认证令牌、学号和成绩不上传拾日后端或模型。跨桥只传课表字段白名单；学校页不是通用原生调用入口。退出/切换账号清理 WebView 会话、缓存、本地存储与实例。Chrome 登录会话不转移到 App。

| --- | --- | --- |
| 河南工业大学 | 正方课表；原站认证后提取课程、星期、周次、节次、地点和教师 | 2026-09-20 用户完成原页认证、读取 17 条记录并确认导入成功；完整性尚未独立对照原站逐项核对 |
| 黑龙江大学 | 本科教务；课程、考试和未排时段实践统一预览 | 2026-10-07 正式 App 真实登录并读取 22 项：16 组课程、4 场考试、2 项实践；取消预览，未确认覆盖已有课表 |

未适配学校不能标成已支持；保留手工录入/文件或截图的兜底。兜底成功不能记为教务登录成功。当前同步是用户主动重导入与差异确认，不承诺后台持密码定时登录。

## 河南工业大学

公开依据为学校[综合教务访问说明](https://www.haut.edu.cn/info/1311/508351.htm)（2020 年历史说明）与[原始登录页](https://jwglxt.haut.edu.cn/jwglxt/xtgl/login_slogin.html)。早期 2026-09-19 调研只验证公开页及前端协议；公开 HTTP 200 不等于认证和课表读取成功。

读取器见[haut_reader.js](../apps/mobile/assets/haut_reader.js)。学年/学期编码、课表菜单和实际字段依学校当前页面读取，不把第一/第二学期猜成固定 1/2。曾遇到校方改写数组 filter 回调顺序导致白名单字段为空，读取已改用索引循环；诊断不记录个人身份或完整课程明细。

用户于 2026-09-19 已确认协调教务接入使用事宜，无需重复确认；这不替代登录、完整性和手机兼容性的技术验证。早期第三方适配仓库仅作协议线索，未核实许可的代码不直接移植。

## 黑龙江大学

入口依据为学校[查看课表通知](https://jwc.hlju.edu.cn/info/1059/3077.htm)。认证在 [sso.hlju.edu.cn](https://sso.hlju.edu.cn/cas/login?service=http%3A%2F%2Fxsxk.hlju.edu.cn%2Fcas) 原页；本科课表 `xsxk.hlju.edu.cn` 使用 HTTP，Android 仅对该必要域开放明文连接，其他域保持限制，不关闭 TLS 证书验证。不是研究生平台或整套教务功能适配。

读取器见[hlju_reader.js](../apps/mobile/assets/hlju_reader.js)，兼容脚本见[hlju_browser_compat.js](../apps/mobile/assets/hlju_browser_compat.js)：

- 已识别 DOM 为课表主事实；学校元数据只补已核实钟点和首周，不用未校准响应覆盖 DOM。
- 校方 mobile:false 检查会误报新版移动浏览器；App 使用保留真实版本的桌面 UA。在原始教务来源注册 Document Start 兼容脚本，使缺失朗读描述对象不再中断页面；播放请求明确失败。SSO 页面不注入，退出移除注册。
- 原教务页按桌面宽度展示并允许缩放，避免禁止缩放的引导按钮落在手机视口之外；初始化/加载失败可见，快速退出不继续导航。
- 实际作息接口 `/component/queryKbjg` 的 `content` 使用小写 `xj/kssj/jssj`、全周共用。已有真实会话读取 14 行，保留第 1—12、14、15 节，不补不存在的第 13 节。
- 已有真实课表学校首周为 2026-08-24，App 原设置为 2026-08-31；预览明确显示差异，用户可采用或保留本机骨架，确认前不变更。
- 课程保留明确整段钟点和课间，未知实践保持无具体时刻。免听保留记录但不占容量、统计分钟或上课提醒；不要虚构作息套用默认节次。

## 学期维护与重导入

入口为“学期 → 管理学期与课表”。名称、首周周一、总周数、节次可编辑；节次任意分钟且当天结束晚于开始。总周数不能短于课程使用的周次，引用中的节次不能被悄悄删除。保存时间骨架后重算普通课次、保留明确调课并提示受影响计划，不自动移动个人安排。

同一课程多组授课模式先选具体组。课程删除预览给出实际范围；相关任务保留、解除课程关联，历史修订保留。学期删除列明课程、事项、日程、计划、来源、对话和历史范围；删除最后一个学期回到创建入口。

重导入按学校/来源学期、稳定标识与已读取范围匹配，展示新增、变化、来源缺席、未变化与不明确项。重复不重复创建；同名无法唯一匹配不猜。旧课未出现默认保留，只有明确选中才移除，手工添加/修正和其他来源学期不纳入自动移除。读取失败或空响应不表示全部停课。

考试/实践与课程使用同一核对流程，保留用户已编辑或取消的附加记录。缺首周、缺节次或超出周数显示具体值与返回设置入口。已确认调课和较新通知不能被较旧导入静默覆盖。跨设备同步空学期目录也须清旧缓存并重算本机提醒。

## 图片与语音

| 来源 | 输入规则 | 识别 |
| --- | --- | --- |
| 图片 | 系统选择器；JPEG/PNG/WebP，最多 10MB、2000 万像素，拒绝动画；验证文件内容、处理方向、去 EXIF，规范化 PNG 存储上限 30MB | RapidOCR/ONNX Runtime CPU 识别，不用文件名作为文字 |
| 语音 | 用户主动授权录音；16kHz 单声道 16 位 PCM WAV，最多 120 秒/20MB；后台停止，上滑取消；本机/来源页回放 | sherpa-onnx SenseVoice int8，去控制标记，不用情绪标签判断用户 |

模型安装见[setup_media_models.py](../scripts/setup_media_models.py)。模型置于 `.local-data/models` 或云端只读目录，不进入 Git/APK；包下载检查成员路径/类型与已核实 SHA-256。OCR/ASR 在独立 CPU 进程执行，原媒体不发送文字模型。机器原文、校对稿、原消息时间和识别元数据保留，结果交给统一助手；正式事项/变化仍需预览确认。

图库/麦克风权限拒绝、识别失败或模型不可用时可手工填写；未成功关联原文件则如实说明。删除服务端原文件保留文字、历史和已保存事项，显示原文件已删除。多条事项按组核对，不承诺一次完整识别任意课表或考试表。

## 来源、队列与草稿

媒体来源归用户和学期，随机存储键，不按用户文件名造磁盘路径；内容读取须鉴权，API 不暴露磁盘路径。上传幂等按用户/学期隔离，同键不同文件拒绝；每用户最多500份未删除原文件、合计1GB，达到配额提示处理原文件，不静默删除已保存来源。

识别状态区分 uploaded、queued、running、recognized/failed、cancelled。数据库租约/尝试次数与行锁防重复发布；中断可重领，耗尽后明确失败供重试。取消推进来源版本，底层推理不保证立即停止，但旧租约/版本无法发布。来源改动后旧候选确认再次核对版本。

账号/学期分别保存文字与媒体草稿、校对稿、消息时间、来源/本机文件及未保存状态。图库进程回收只恢复当前匹配草稿，切换账号不混入旧选择结果。来源保存响应绑定 ID 与操作序号；取消或切换不能把 A 回执写到 B。服务器新版本不能自动覆盖本机稿。

上传重试复用标识，请求出错先查询已接收状态。退出清理本机私有副本，已授权录音接入失败保留原稿，接管成功后清理临时 WAV；播放释放后清临时文件。正式来源不因退出账号自动删除。

## 验证边界

历史合成 PNG/TTS 已走通真实 OCR/ASR/模型/确认闭环；它不代表真人语音准确率。已有 Android 模拟器学校原页及黑大真实预览，不代表物理手机/OEM兼容性。首次重导入完整性、真实麦克风与相册链路、校园网/校外网络、失效重登仍应按[测试要求](测试与比赛说明.md)留证，不用截图、匿名样本或已取消预览替代保存验收。
