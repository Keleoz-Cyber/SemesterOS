# 拾日1.1.1交付说明

发布日期：2026-10-17。Android版本 **1.1.1**、构建号 **12**；后端版本 **1.1.1**。

## 本次更新

- 分类和标签使用共享程序词表，文字提取不再自由生成大量标签；无需调用LLM完成标签处理。
- 组会、座谈会、班会、例会统一为会议；彩排、联排统一为排练；讲座、实验作业、运动等同用途名称归并。
- 已有标签自动整理，取消整理完成提示和分类筛选排，保留搜索与分组列表。标题、通知原文和时间保持原样，旧ID和旧名称继续识别。
- 标签名称可打开关联事项及日程，支持跨学期、完成和取消状态、详情、分页、重试与账号隔离。
- 版本、反馈提交、使用说明、功能清单、接口索引、开发设计、Word及参赛资料同步更新。旧界面测试按实际管理菜单调整。

此前已交付的课表导入、课次调整、通知识别、手动记录、学习排程、减少移动的重排、保存核实与撤销、统计、桌面卡片、系统提醒、搜索、反馈、导出和注销等继续保留，完整入口见[使用说明](产品规则.md)及[功能清单](功能清单.md)。

## 部署与资料

API和worker使用同一发布镜像，发行目录 `/opt/semesteros/releases/v1.1.1-build12`。发布前备份，迁移头仍为 `0018_personal_data`，本版无新增表迁移。健康结果和部署日志存于本机 `output/verification/v1.1.1-deploy.log`；失败由既有发布脚本恢复原镜像与配置。

文档入口见[目录](README.md)。当前维护稿覆盖App各功能，Word设计资料与视频脚本同步；比赛规则和原始测试文件保留原日期。既有视频4分52秒、54,386,609字节，完整48秒片头；本次App发版未重制旧录屏。

## 使用范围与待补

正式平台为Android，学校适配为河南工大与黑大。普通提醒由系统闹钟调度；Android16增强通知和不同厂商省电策略由系统控制，不能将模拟器结果推广到所有手机。强行停止后需要重开App核对。

保留有限缓存查看与离线延后；保存、正式完成、助手和排程需要服务端。个人耗时学习、自动每日复盘、更多学校、团队协作、反馈工单回复和App深色切换尚未交付。用户提供的意见文字未构成统一招募的用户研究，未填造用户规模、准确率或提效比例。
