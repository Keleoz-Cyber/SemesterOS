# 拾日 1.1.1 交付说明

发布日 2026-10-17。Android 版 **1.1.1**、构建号 **12**；后端 **1.1.1**。

这一版主要在标签上动刀：分类和标签改用程序词表，文字提取不再自己编一堆标签出来，整条链上都不调模型。顺带把版本号、反馈提交、使用说明、功能清单、接口索引、开发设计、Word 和参赛资料一起更新了，旧界面测试按现在的管理菜单调过。

之前交付的那些——课表导入、课次调整、通知识别、手动记录、学习排程、少挪动的重排、保存核实与撤销、统计、桌面卡片、系统提醒、搜索、反馈、导出、注销——都还在。入口看[使用说明](产品规则.md)和[功能清单](功能清单.md)。

## 这一版改了什么

- 分类、标签共用一份程序词表，标签处理不再调 LLM。这是 1.1.1 最实质的改动，线上合成检查里标签的 LLM 调用次数是 0。
- 组会、座谈会、班会、例会统一成“会议”；彩排、联排统一成“排练”；讲座、实验作业、运动这些同用途的名字也做了归并。
- 已有标签自动整理，去掉了“整理完成”的提示和分类筛选那一排，搜索和分组列表留着。标题、通知原文、时间一个字不动，旧 ID 和旧名称还能认。
- 点标签名能打开关联的事项和日程，跨学期、已完成、已取消都在，支持详情、分页、重试，也做了账号隔离。
- 版本、反馈提交、使用说明、功能清单、接口索引、开发设计、Word、参赛资料同步。

## 部署和资料

API 和 worker 用同一个发布镜像，发行目录是 `/opt/semesteros/releases/v1.1.1-build12`。发布前备份过，迁移头还是 `0018_personal_data`，这版没有新增表迁移。健康结果和部署日志在本机 `output/verification/v1.1.1-deploy.log`；真出事由现有发布脚本退回原镜像和原配置。

文档入口见[目录](README.md)。当前维护稿覆盖 App 各功能，Word 设计资料和视频脚本也同步了；比赛规则和原始测试文件保留原日期，不动。现有视频 4 分 52 秒、54,386,609 字节，带 48 秒片头。这次发 App 没有重制旧录屏。

## 用起来是个什么范围

正式平台是 Android，学校适配是河南工大和黑大。普通提醒交给系统闹钟；Android 16 的增强通知和各家厂商的省电策略由系统说了算，模拟器上过了不能推成所有手机都这样。强行停止之后得重开 App 核对一遍。

保留了一部分缓存查看和离线延后；保存、正式完成、助手、排程都得连服务端。还没交付的：个人耗时学习、自动每日复盘、更多学校、团队协作、反馈工单回复、App 内深色模式切换。用户给的文字意见算不上统一招募的用户研究，所以没填用户规模、准确率、提效比例这些数。
