# 版本与交付说明

当前版本为 **1.1.0，Android构建号11**，后端版本为1.1.0。本次统一更新版本标识，功能完善和验收记录见[本轮完善进度](本轮完善进度.md)。下表同时保留此前的可靠性修复说明。

## 本次改动

| 内容 | 处理结果 |
| --- | --- |
| 上传并发 | 图片处理与数据库事务分开，数据库使用线程内独立会话；统一加锁顺序，配额仍按账号核对 |
| 密码重置 | 创建会话前锁定用户并重新读取密码状态，拒绝跨过重置的旧密码登录 |
| 刷新响应丢失 | 同次请求可在120秒内重试取回同组令牌；客户端保存请求标识，并处理迟到的旧令牌401 |
| 认证限流 | 登录、注册和恢复分别限流；刷新按会话限制，刷新与退出不再共用小额登录额度 |
| 退出清理 | 凭证、学校登录、缓存和提醒独立清理；失败可重试，未清除凭据时阻止下次自动恢复旧登录 |
| 离线延后 | 本机账号、通知和缓存核对后，可断网延后10分钟；标记完成仍需联网 |
| 河南工大作息 | 按用户提供的10节时间预填，与课程一并确认和保存，取消预览不改当前作息 |
| 节次列表 | 创建和修改学期时直接显示全部节次，保留滚动与增减操作 |
| 导入返回 | 从使用说明进入导入页后能返回原页，直接进入也有返回入口 |

## 安装包

- [拾日-1.1.0.apk](../output/apk/拾日-1.1.0.apk)
- 包名：`cn.semesteros.semester_os`
- 最低Android版本：7.0（API 24）
- 架构：`armeabi-v7a`、`arm64-v8a`、`x86_64`
- 大小及校验值以本次构建的[manifest.json](../output/release/manifest.json)为准。
- 服务地址：`https://semesteros.keleoz.com`

SHA-256见[SHA256SUMS.txt](../output/release/SHA256SUMS.txt)。

已核对升级兼容的签名、版本号和三个架构中的新客户端代码，并覆盖安装到模拟器。64位库的16KB对齐检查通过，但这不等于已在16KB页面大小的物理设备上测试。

## 验证与部署

本次版本升级的API、健康检查及OpenAPI版本契约测试通过。此前功能完善已通过PostgreSQL全套578项、Flutter全套584项和Android 16完整操作验收；本次没有改变业务流程。较早的节次、返回导航和离线延后记录见[历史检查记录](参赛资料/验证证据/fixes-20261010/README.md)。

后端API和worker使用同一发布镜像，数据库迁移为`0018_personal_data`，本次版本升级没有新增数据库迁移。历史部署核对见[2026-10-10记录](参赛资料/验证证据/fixes-20261010/cloud-verification.json)，当前部署结果见`output/verification/v1.1.0-deploy.log`。

本次使用合成数据和模拟器，没有重新验证真实教务账号登录、物理手机或各厂商省电策略。离线延后使用本机已知记录，尚未同步的取消或修改会在联网后校正。
