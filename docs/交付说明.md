# 版本与交付说明

当前安装包为 **1.0.0，构建号9**，后端版本为1.0.0。本次交付包含上传、认证、退出、提醒和课程导入的修复。

## 本次改动

| 内容 | 处理结果 |
| --- | --- |
| 上传并发 | 图片处理与数据库事务分开，数据库使用线程内独立会话；统一加锁顺序，配额仍按账号核对 |
| 密码重置 | 创建会话前锁定用户并重新读取密码状态，拒绝跨过重置的旧密码登录 |
| 刷新响应丢失 | 同次请求可在120秒内重试取回同组令牌；客户端保存请求标识，并处理迟到的旧令牌401 |
| 认证限流 | 登录、注册和恢复分别限流；刷新按会话限制，刷新与退出不再共用小额登录额度 |
| 退出清理 | 凭证、学校登录、缓存和提醒独立清理；失败可重试，未清除凭据时阻止下次自动恢复旧登录 |
| 离线延后 | 本机账号、通知和缓存核对后，可断网延后10分钟；标记完成仍需联网 |
| 河南工大作息 | 按用户提供的10节时间预填，与课程一并确认和保存，取消预览不改当前作息 |
| 节次列表 | 创建和修改学期时直接显示全部节次，保留滚动与增减操作 |
| 导入返回 | 从使用说明进入导入页后能返回原页，直接进入也有返回入口 |
