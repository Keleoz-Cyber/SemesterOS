# 学期与课程基础维护闭环

用户指出现有“管理学期与课表”只能新建、不能删除，合成 QA 学期的周次与节次设置也会阻断真实课表重导入。本轮补齐维护和恢复路径，没有自动删除任何现有账号的数据。

## 用户可执行的操作

- 当前学期可修改名称、第一周周一、总周数和逐节上课时间。修改时间骨架前显示旧／新差异；服务器以学期修订号校验，重新计算已导入课次。周数不能小于课程实际使用的最大周次，已有课次不能引用缺失节次。有活动中的个人计划或已确认调课时，先要求处理这些依赖，不静默移动或覆盖。
- 节次列表底部提供并排的 `＋`／`－` 图标按钮，分别追加一个可改时间的节次或移除最后一节；保留逐节时间选择和批量编辑。
- 当前学期可查看删除范围，再明确确认删除。课程、事项、日程、个人计划、来源和助手对话及相关历史随学期删除；删除最后一个学期后清除本机课表、事项草稿与待投递提醒。其他学期和账号不受影响。
- 单门课程可编辑名称、教师、地点、星期、周次与节次，并在保存前核对变化；可查看关联事项数量后删除课程。删除课程保留任务，但解除课程关联并清空任务卡上的旧课程名，历史原因仍留在事项修订中。
- 教务重导入若超出学期周数或缺少节次，错误指出具体周／节，预览提供进入学期设置的入口。若课程信息变化，显示旧／新课程详情，需明确勾选才替换；同名多课无法唯一匹配时拒绝猜测。新课表未出现的旧教务课程另列清单，默认保留；只有勾选才移除。手工添加及后来手工修正的课程不计入这一自动移除范围。

## 数据与清理

- 课程和学期的修改、删除均使用修订号，旧页面请求返回冲突并要求重新读取。
- 删除学期时，数据库在同一事务中记录媒体文件清理任务。文件删除失败会保留任务供后续请求或服务启动重试；不会在数据库提交前移走仍有引用的文件。
- 本机账号缓存按学期清理。另一设备删除最后一个学期后，本机同步到空目录也会清除旧事项缓存并重新同步系统提醒。
- 新增 Alembic `0013_semester_cleanup`，为课程记录增加手工修正标志，并建立媒体清理任务表。对现有 QA 数据库只做增量迁移。
