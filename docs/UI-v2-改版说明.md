## 动效与细节

十二个模式对应实际入口：日出、主标签／路由 fade-through、首次列表交错、服务器确认完成、选中弹簧、数字滚动、空档填充、课程／任务／胶囊容器过渡、胶囊折叠、真实按住说话及取消、整分钟现在脉冲、共用骨架。隐藏、后台、被弹层盖住以及减少动画时，展示计时器和动画停止或直接终态。

模糊只在导航坞和胶囊；低端回退由连续慢栅格帧判断，也支持系统减少动画／高对比度的不透明回退。此为代码策略，没有据此宣称帧率、内存或首屏百分比提升。列表行无逐行阴影，关键卡片和悬浮层才使用对应阴影。

独立代码审查发现并修复了：跨日 Hero 重名、录音跨学期接入、重复页头与冻结时钟、七天目标不足48dp、已取消计划仍称已安排、动画中途减少／覆盖后未终态、释放时才创建ticker、固定页脚挡住确认、真实课程被当空档压缩。录音作用域用账号／学期／代际 key 与回调快照双重核对，已授权文件接入失败保留原稿。

原生走查额外发现助手弹层的显示和点击位置错位。回归用例确认：过渡首帧尚无尺寸时返回裸 Sheet，下一帧加 Transform 包装，导致助手和 sheet model 重挂载。现保持同一包装结构，未测量时用恒等变换，减少动画时也只切到终态。检查保留第一帧 State、键盘前后命中位置与真实历史消息，避免只测过渡后的截图。

## 业务边界与取舍

- API、数据库、业务控制器、学校 WebView／脚本／解析、提醒服务、路由 URL 与含义未改。route extra 仅提供标题／过渡 tag，数据与写入仍来自原接口。
- 确认、撤销、回执、版本冲突、未知结束与个人听课状态保持原流程。右滑和就地预览没有乐观保存／乐观划线。
- 首页原显隐、模式、手工顺序及三种日程模式保留。本周条形接原“本周忙闲”模块，不强制改旧偏好或默认多发周查询；验收图册在合成账号显式开启该模块。
- 天空叠压的28dp折算到真实sliver布局空间，取消负位移，避免标题被固定页头盖住或触控落在布局外；大字按实际日期、数字和标签测量。
- 密集七列课表按MASTER保留紧凑网格，不能把所有网格块宣称为48dp；完整日期列表、单日和详情提供更大的操作区域。周表长地点仍可能裁短，完整列表／详情保留全文。其他关键动作和可滚动分段保持至少48dp。
- 匿名落实于新增品牌、插画、演示素材和通用教务页头；学校选择所需学校名保留，用户已填资料和原教务网页的功能事实按MASTER保留，不改原数据或网页。
- 浅色为本次交付。深色主题保留供第二阶段，尚未逐页走查；“长按空白格快速添加”在规范中仅为建议，本次沿用原新建入口，未新增操作流程。
