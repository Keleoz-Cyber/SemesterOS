# 手机布局与任务密度修正

本轮针对真实截图中的三处问题，并检查四个主页面在普通字号、1.6 倍字号、320dp／2 倍字号和横屏下的布局。改动只涉及移动端展示和对应测试；服务器与数据模型未改。

## 已调整

- **日程**：手机周模式从七列窄网格改为按日期分组的日程流，显示完整标题、时间、类型和地点；平板/宽屏仍保留周网格。可横滑日期条，选中日期会滚入可见区域，普通数据刷新不强制改变用户已滑动的位置。当天当前时间有时间线标记。
- **任务**：列表卡收拢标题、分类、截止时间、剩余耗时；只在有明确风险或余量时显示一行结论，点开仍能看计算依据。移除列表内重复的进度/完成按钮；详情功能保留。七条任务的复现实测中，带风险卡从 209dp 降到 151dp，普通卡从 121dp 降到 100dp（390dp 宽度）。
- **学习安排**：移除浅色外框套白卡片，改为时间、任务和锁定状态对齐的时间线。三段计划总高度 282dp，其中每段 62dp，标题与操作各 48dp。
- **学期**：周次概览和周选择器收紧，重要节点改为连续日期轨道，减少逐条大卡；节点的日期、名称、类型和时间仍可见。

- `flutter test --no-pub`：306 项通过；覆盖日／周切换、日期条定位、七条任务密度、三段计划密度、学期节点、普通/大字号/320dp/横屏及键盘布局。
