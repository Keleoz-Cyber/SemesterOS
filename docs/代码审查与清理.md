# 代码审查与清理

日期：2026-10-04。审查当前工作区的移动端、后端、原生入口、部署/验证脚本及文档；依据实际运行入口与引用关系清理，不以“未提交”作为删除依据。

> 后续已完成 PostgreSQL 13 项、后端发布和新版 APK / 模拟器流程；见[发布与流程验收](2026-10-04-发布与流程验收.md)。下文的未发布状态属于审查收尾时点。

## 清理结果

- 删除 **107 个文件**：93 份过期报告、重复执行计划、旧浏览器原型/视觉参考或废弃工具，以及 14 个不可达的移动端页面/演示和对应死测试。
- 删除活文件内的旧键盘时间输入、无行为兼容参数、旧课程卡片/布局算法、未用动画与辅助函数；保留实际提醒、草稿、共享语义控件和课程详情。
- 清理后端 25 个未用导入与 1 个恒假分支。
- 移除 4 个多余直接依赖声明；`cupertino_ui`、`material_ui` 仍由 Forui 间接使用，锁定版本保留，其余现有依赖未升级。后续 Release 字体检查确认 go_router/SDK 的兜底导航仍引用 Cupertino 字体，已恢复 `cupertino_icons` 字体资源依赖。
- 精简 README、设计系统、部署与维护说明，修复遗留 QA 工具的导航/输入入口及历史图册链接。原比赛 PDF、用户反馈、业务迁移、数据库与媒体保留。

## 已修复问题

| 范围 | 修复 |
| --- | --- |
