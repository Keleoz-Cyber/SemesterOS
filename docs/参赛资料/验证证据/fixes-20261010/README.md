# 这次修复的验证

记的是 1.0.0 构建 9 的修复检查，合成账号加 Android 13 模拟器。

- 后端在独立的 PostgreSQL 里跑完了全套回归，544 项通过，没有跳过。
- 最后改的是上传的加锁顺序，改完又单独跑了上传、标签、认证、学期相关 35 项，全过。现在的顺序是先锁学期再锁账号；助手那边上传还会先锁对话，免得跟别的写入互相等。
- Flutter 全套 579 项通过，静态检查没有问题。
- 模拟器上确认了河南工大那 10 节时间跟着课程一起存下来，节次能全部展开，导入页也能退回使用说明。
- 关掉 Wi-Fi 和移动数据，通知上的“延后”按钮能排上本地提醒。后台进程被 ActivityManager 干掉之后，同一个操作也做成了。这跟系统设置里的“强行停止”不是一回事，别混着说。
- API 和 worker 都更新了，数据库升到 `0017_auth_and_import`，线上代码校验和本地一致。

汇总在 [results.json](results.json)。后端日志、截图、界面 XML、通知记录都在，用来核实际发生了什么。正式安装包的信息也在这个汇总里。
