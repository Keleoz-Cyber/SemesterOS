# 拾日完整使用说明

适用版本：**1.1.1（Android 构建号12）**，2026-10-17。

拾日把课程、日程、待办、考试和学习安排放在同一个学期中。可以手动记录，也可以让助手整理消息。第一次使用时，先导入课表，再记一项待办，就能开始使用；自动安排学习时间可以稍后设置。

## 1. 账号和首次使用

注册后保存恢复码。忘记密码时，使用账号和恢复码重置；恢复码应由自己妥善保管。登录状态会自动刷新，暂时断网时可先查看本机缓存。

新建学期时填写名称、第一周周一、总周数和每天的节次。节次列表直接全部展示，可以逐行修改、增减。之后可从学期管理切换、重命名、编辑或删除学期。

使用说明可以从账户页再次打开。说明中的课程、通知、任务入口能直接进入相应页面，并保留返回路径。

个人资料可以填写学校、专业、年级、学期情况和学习偏好。软件已有功能不以完整填写所有资料为前提。

## 2. 四个主页面

| 页面 | 主要内容和操作 |
| --- | --- |
| 今日 | 当天和下一项安排、待办、考试信息、学习空档、本周忙闲；打开详情、搜索或调整首页显示内容 |
| 日程 | 周课表与列表切换，左右切周、回到今天、跳转日期、查看当天详情，新增日程和打开助手 |
| 任务 | 待处理、已完成、已取消事项；手动新增、搜索或筛选、排序、批量处理、进度和学习安排 |
| 学期 | 学期进度、周次活动、课程、考试、统计、标签、导入课表与学期管理 |

底部输入入口可打开助手、选择图片或录音。进入其他主页面后，会保留之前的浏览和滚动位置。

## 3. 课程、考试与请假

从“学期 → 导入课表”选择学校，在内置教务网页自行登录，选择学期、读取并核对后确认。当前有河南工业大学和黑龙江大学适配器；其他学校可以手动添加。

河南工大导入会预填用户提供的10节作息，确认时与课程一起保存。查看预览后取消，不会提前修改原作息。作息仍应核对是否适用于自己的校区和学期，详细时间见[学校接入说明](学校与媒体接入.md)。

课程详情包含课程信息与具体课次。调课、停课和请假按具体日期的课次处理，先核对影响再保存。修改某一次课不会删除整门课。恢复和撤销也要检查当前安排。

“我已请假”只记录自己已经办好的请假，软件不会向学校提交申请或批准请假。“待请假”仍按需要上课计算；已请假的那一次课从普通日程和周课表隐藏，课程及其他周次保留。

日常说“下午第二节课”时，助手按连上的整节课理解，并核对当前学期作息。例如河南工大当前预填作息中，下午第二大节对应第7、8节，从16:25开始。明确说“第7到8节”则直接按编号查询。

考试可以关联课程，填写日期、开始时间、地点和其他说明，在考试列表、日程和今日提示中查看。复习任务与考试记录分别管理。

考试安排变化可在“考试与复习”中核对新时间、原安排和受影响计划。课程详情也可添加关联作业或考试。

## 4. 手动记录日程和任务

日程用于参加会议、活动等；任务用于完成作业、报告等；学习安排是给任务分配的执行时间。安排了30分钟，不代表任务已经完成或剩余耗时自动减少。

手动新增先填标题，按已知情况补充日期、时间、地点、课程、分类、标签、备注和提醒。任务可先不填期限和预计用时，之后再补。详情页提供编辑、状态修改、提醒、历史及向助手提问等入口。

任务支持待处理、已完成、已取消状态。任务列表支持排序和批量操作；实际可用动作以选中记录和当前状态为准。服务端保存成功后才更新完成状态，短时提示中的“撤销”按当前记录检查后执行。

## 5. 时间没有说全时

| 消息 | 保存和显示方式 |
| --- | --- |
| 明天9点到A301开会 | 记录9点开始，结束留空 |
| 周五交报告 | 记录日期，保留具体截止时刻未说明 |
| 第12周考试 | 记录周次，后续可以补充日期和钟点 |
| 10日到12日办理 | 记录可办理窗口，区别于三天连续占用 |
| 周六全天外出 | 按明确的全天安排记录 |
| 有空整理资料 | 时间未知的待办 |
| 8:10候场，9点开始 | 到场和正式开始分别保存 |

没有结束时间的活动可以保存，周课表使用相应的时间点或提示展示。需要排程时，系统会说明哪些时间还无法判断。

## 6. 助手与通知输入

可以输入文字、选择截图、录音，也可以从其他应用通过系统分享把文字或图片交给拾日。识别后的文字先供核对，之后再整理成日程或任务。剪贴板内容由本机检查，出现提示后由自己决定是否发送。

助手可查询课程、活动、任务、空闲和统计，继续补充上一条通知、修改已有记录、生成学习方案。历史列表可以重新打开对话、继续处理、修改输入或删除。

常见说法：

- 明天有什么课？
- 周五下午第二节课开会，地点6108。
- 刚才的会议改到A302。
- 周五12点到14点有没有连续一小时空闲？
- 今晚安排这三项任务，先给我方案。

从日程页进入时，助手可以携带正在浏览的日期范围；输入区可移除这个标记。“明天”仍依据当前真实日期解释。

一段通知包含多件事时会分开整理。预览可以检查字段和来源、补充或直接修改、选择要保存的部分。确认按钮提交后，看到保存回执才表示成功；对话中单独发“确认”不代替按钮。

保存途中断网，可以核实上次结果，重开应用也会检查未完成的保存。已保存但本机尚未同步时，先重试同步，避免重复新建。更正字段不应把后续聊天改写成最初的通知原文。

详情中的“智能修改”可按文字、原图或录音整理修改要求，查看前后变化、调整内容后确认；也能从这里进入指定范围的计划方案。放弃修改不会改变已保存记录。

## 7. 冲突如何处理

新增或修改固定活动时，系统比较修改前后的安排。开始时刻已经落在课程中，会列出冲突课程，提供调整时间、记录已办好请假的具体课次、或明确保留重叠的处理。

只知道上午9:15开始，不能推断下午整段都要请假。后续安排是否受影响，还需要结束时间等信息。已知提前到场的时间也会参与检查。自己不参加、只作参考的活动可以保留信息而不占用个人时间。

会议影响学习计划时，先确认会议，再查看受影响的学习安排。系统不会为了新增活动而自动改掉课程、考试或个人已固定的计划。

## 8. 学习时间、计划与进度

在任务相关入口设置每周可学习时段，可一天填写多个时段，批量选择星期并合并或替换。临时排除时间、每周休息、安排前后缓冲也参与计算。

为需要安排的任务补充预计剩余用时、期限（如有）、最早可开始条件、是否允许拆分及优先级。普通任务没有等待条件时，可以从本次允许的时间开始；明确写了等审批或未来某时开始的，保留该条件。

生成方案后先看任务、时段和未排完的部分，确认后成为正式学习安排。时间不足时显示剩余工作，不缩短任务用时来凑结果。

某一段可以固定，也可取消或允许调整。新增固定活动后，重新规划会保留固定段、保持任务工作量，并尽量减少其他移动。没有选中的任务继续保留。首页的空档建议可进入相关安排，也可选择当天不推荐某任务。

实际学习进度由自己记录，包含用时、剩余情况和完成状态。当前尚未根据每个人的历史耗时自动学习估时，也不会未经确认自动滚动改排第二天的计划。

任务的“时间评估”可查看剩余工作、可用时段、同期任务共同占用及时间如何扣除，已有安排变化后需要刷新评估。它依据当前记录估算，不是执行结果的保证。

## 9. 标签与分类

进入“学期 → 标签”可搜索标签或分组。已有标签会自动整理，过程不额外弹合并提示。新标签保存时也使用统一名称：

- 组会、座谈会、班会、例会 → 会议。
- 彩排、联排、排演 → 排练。
- 分享会、学术讲座、报告会 → 讲座。
- 实验报告、实验课作业、上机作业 → 实验作业。
- 篮球、足球、羽毛球、健身、跑步等 → 运动。

课程名称、不同动作和自定义名称仍保留有用的区别，例如Python与Java、面试与笔试、排练与演出。具体活动称呼保留在事项标题和通知原文中。

系统按内容把标签放入课程与学习、科研与竞赛、会议与交流、文体活动、校园事务、求职与实习、生活日常等分组。分类和标签的推断、统一名称都由程序规则处理，不调用大模型接口。

点标签名称可查看关联事项和日程，列表显示时间、地点和完成或取消状态，包含其他学期的记录；点记录继续打开详情。右侧“更多”保留手动重命名和合并，手动操作先显示影响供核对。标签属于账号，可以跨学期使用。

## 10. 搜索与统计

从首页搜索可查课程、日程、任务、考试及通知来源文字，支持按内容类型查看和继续加载结果。点结果进入详情。

“学期 → 统计”按日期范围、分类或标签查看安排、占用和学习进度。已排时长、去重后的时间占用和实际记录是不同数据；只有开始而缺少结束的信息不会被算成虚构时长。统计中的完成情况依据已保存的状态和进度。

## 11. 本地提醒

在事项或日程详情添加提醒，可以按开始或截止时间提前，也可在支持的事项中指定提醒时刻。修改、完成或取消记录后会重新同步。提醒设置可查看权限、静默时段和已设置情况。

提醒交给Android系统调度。通知权限需要允许；精确闹钟未允许时使用非精确调度，可能延后。静默时段只影响声音和震动，保留原定提醒时间。

通知中的“10分钟后提醒”可依据本机账号、通知和缓存离线执行，联网后再核对记录是否变化。“标记完成”涉及正式业务数据，需要服务端确认。

返回桌面、锁屏、划掉最近任务与系统设置里的“强行停止”不同。强行停止会影响系统闹钟，需要重新打开App核对；不同厂商的电池管理也可能影响送达。可从“桌面卡片与实时提醒”发送测试通知、查看本机清单和进入系统电池设置。

## 12. 桌面卡片、快速记录与进行中通知

在账户相关入口打开“桌面卡片与实时提醒”，可添加桌面日程卡。卡片显示本机已同步的后续安排和同步信息，点卡片可进入详情或快速记录。它使用同步后的数据，不能代替网络上的即时更新。

临近15分钟或正在进行的安排可手动开启跟踪。已知结束时间时显示倒计时，未知结束时显示已开始多久；可以停止跟踪，结束后撤下，未知结束的跟踪最长保留12小时。

Android16及以上会申请系统增强展示，状态栏是否显示胶囊取决于系统权限、资格和厂商。其他版本使用普通进行中通知。这些功能使用系统接口，没有通过空转后台服务保证进程常驻。

## 13. 历史、撤销和来源

修改记录和回执可以核对前后内容，允许撤销的操作先检查当前状态。若恢复旧内容会造成新冲突，系统会说明原因并保持现状。

通知来源详情可查看识别文字、图片或录音，重试识别、修正文字或删除附件。删除附件保留已保存安排与核对所需文字；删除对话会停止该对话尚未完成的处理，保留已确认的业务记录。

删除学期会先列关联数量，确认后删除该学期课程、日程、事项、计划、来源和对话。需要保留的资料应先导出。

## 14. 反馈、导出、退出与注销

从“账户 → 反馈问题”选择识别、保存、提醒、界面或其他问题，填写原操作、实际结果与期望。反馈保存在服务器，开发者通过维护工具查看。当前没有应用内反馈工单进度或自动回复功能。

“数据与隐私”可将个人记录导出为JSON，自己选择系统保存位置。导出涵盖课程、安排、任务、计划、提醒、对话等结构化数据及识别文字；原始图片和录音通过来源详情管理，导出不包含登录凭证。

退出会清理登录状态、本机账号缓存、学校登录信息、卡片和提醒；失败时按提示重试。注销需输入密码及“删除我的账号”，删除账户及关联数据，文件清理由后台继续处理。已导出到自己文件夹的独立文件由自己管理。

## 15. 网络和当前范围

缓存可用于查看已同步内容，助手、导入确认、保存、正式任务完成和重排需要连接后端。暂时离线时先保留输入；遇到旧预览或记录已变化，刷新后重新核对。

当前正式交付为Android应用及服务端，已有两所学校适配器。更多学校、跨用户协作、个人耗时学习与自动复盘尚未实现。深色数值存在于设计代码，但App还未提供深色模式切换。
