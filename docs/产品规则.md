# 拾日完整使用说明

适用版本 **1.1.1（Android 构建号 12）**，2026-10-17。

拾日把课程、日程、待办、考试和学习安排放在同一个学期里。你可以一个字一个字手打，也可以把群消息丢给助手让它整理。第一次用的话，导入课表、记一条待办就够上手了，学习时间可以以后再说。

## 1. 账号和第一次打开

注册完先把恢复码存好，别只截个图放相册里——换手机、清缓存都会用到它。忘记密码就靠账号加恢复码重置。登录状态会自己续，短暂断网时还能翻本机缓存里的内容。

建学期要填四样：名称、第一周的周一、总周数、每天的节次。节次列表一次全展开，你可以一行一行改，也能加一节删一节。以后在学期管理里能切换、改名、编辑、删除。

使用说明在账户页里还能再打开一次，里面的课程、通知、任务入口点了能直接跳过去，返回也能回到原来那页。

个人资料填学校、专业、年级、学期情况、学习偏好，这些都不影响功能能不能用，空着也行。

## 2. 四个主页面

- **今日**：当天的安排、下一项、待办、考试提醒、学习空档，还有这周的忙闲。点进去能看详情；首页放几块内容、什么顺序，可以自己调整。
- **日程**：周课表和列表两种看法，左右切周、回今天、跳日期都行，点某天能看当天详情，也能直接新增日程或喊助手。
- **任务**：待处理、已完成、已取消都在这里。手动新增、筛选、排序、批量处理、记进度、排学习时间。
- **学期**：学期进度、周次活动、课程、考试、统计、标签，以及导入课表和学期管理。

底部那个输入口是助手、图片、录音的入口。切到别的主页面再切回来，之前的浏览位置和滚动位置都还在。

## 3. 课程、考试和请假

在“学期 → 导入课表”里选学校，App 会打开内置的教务网页，你自己登录，然后选学期、读取、核对、确认。现在只有河南工业大学和黑龙江大学两个适配器，别的学校只能手动录入。

河南工大的导入会顺手把你提供的 10 节作息预填进去，跟着课程一起确认保存。如果预览后点了取消，原来的作息不会被改。不过这套作息到底适不适合你的校区和学期，还是得你对一下，具体时间在[学校接入说明](学校与媒体接入.md)。

课程详情里分两块：课程本身，和一门课下的具体课次。调课、停课、请假都是按某一天的某一次课处理，存之前先看它会影响什么。改一次课不会把整门课删掉；恢复和撤销同样要检查当时的安排。

“我已请假”只记一笔账，软件不会替你去学校提交申请，也不会批假。“待请假”按仍然要上课算。已经请假的那一次课会从普通日程和周课表里隐掉，课程和其他周次照旧。

说“下午第二节课”的时候，助手按连着上的整节课理解，会去对当前学期的作息。比如河南工大现在预填的作息里，下午第二大节是第 7、8 节，16:25 开始。你要是明说“第 7 到 8 节”，它就按编号查，不做推断。

考试可以挂到课程下，填日期、开始时间、地点和说明，之后在考试列表、日程和今日提示里都能看到。复习任务和考试记录是两回事，各管各的。

考试时间变了，在“考试与复习”里核对新时间、原来的安排、以及哪些计划被影响。课程详情里也能顺手加关联的作业或考试。

## 4. 手动记日程和任务

这三个概念别混：**日程**是会议、活动这类有明确时间的事；**任务**是要交的作业、报告；**学习安排**是你给任务分配的执行时间。安排了 30 分钟，不代表任务做完了，剩余时长也不会自动扣。

新增时先写标题，其余按你手头知道的填：日期、时间、地点、课程、分类、标签、备注、提醒。任务可以先不填期限、不填预计用时，以后再补。详情页上有编辑、改状态、加提醒、看历史、向助手提问这些入口。

任务有三个状态：待处理、已完成、已取消。列表能排序、能批量操作，但具体哪几个动作可用，取决于你选中了哪些记录、它们当前是什么状态。完成状态要等服务端存成功才变；短提示里的“撤销”会先看当前记录再决定能不能撤。

## 5. 时间没说完的时候

这是拾日最想解决的一类情况，直接看例子：

| 你说的话 | 存成什么 |
| --- | --- |
| 明天9点到A301开会 | 9 点开始，结束时间留空 |
| 周五交报告 | 记下日期，具体截到几点没说明就空着 |
| 第12周考试 | 只记周次，日期和钟点以后再补 |
| 10日到12日办理 | 记成一个可办理的窗口，不等于三天都被占满 |
| 周六全天外出 | 按全天安排记 |
| 有空整理资料 | 时间未知的待办 |
| 8:10候场，9点开始 | 到场时间和正式开始分开存 |

没有结束时间的活动照样能保存，周课表会按已知的时间点或者一句提示来显示。真到要排程了，系统会明确告诉你哪些时间还算不出来，而不是替你猜一个。

## 6. 助手和通知输入

能喂给助手的有四种：打字、选截图、录音，以及从别的 App 用系统分享把文字或图片递过来。识别出来的字先给你核对，确认没认错，再整理成日程或任务。剪贴板是在本机检查的，弹了提示之后发不发还是你说了算。

助手能查课程、活动、任务、空闲时间和统计，能接着上一条通知往下补，能改已有记录，也能生成学习方案。历史列表里的对话可以重新打开、继续聊、改掉自己输入的内容，或者删掉。

几句常用的话：

- 明天有什么课？
- 周五下午第二节课开会，地点6108。
- 刚才的会议改到A302。
- 周五12点到14点有没有连续一小时空闲？
- 今晚安排这三项任务，先给我方案。

从日程页进助手时，会带上你正在看的那段日期，输入区里能把它去掉。“明天”始终按当天真实日期算，不会跟着你翻到的那一周跑。

一条通知里塞了好几件事，会拆开分别整理。预览页能看字段、看这段话是从哪来的、补内容、直接改，也能只勾选要存的那部分。点了确认按钮、并且看到保存回执，才算真的存上；光在对话里打一句“确认”不算，那是为了防止手滑。

保存到一半断网了，可以回过头核实上一次的结果，重开 App 也会检查有没有没做完的保存。如果显示“已保存但本机还没同步”，先去重试同步，别急着再建一条，不然容易出重复。改字段的时候，不要把后面的聊天记录改写成最初那条通知的原文，两边的用途不一样。

详情页的“智能修改”可以用文字、原图或者录音来说明你想怎么改，它会给出前后对照，你调整完再确认；也能从这里直接进某个范围的计划方案。中途放弃，已保存的记录一点不变。

## 7. 撞车了怎么办

新增或修改一个固定活动时，系统比的是改之前和改之后。如果开始时刻正好落在某节课里，它会把这节课列出来，然后给你三条路：改时间、给具体那一次课记一笔“已办好请假”、或者你明确表示就是要重叠。

只知道 9:15 开始，推不出下午整段都要请假。后面会不会受影响，得等结束时间这些信息补齐。已知要提前到场的时间也会算进检查里。自己不去、只是留个参考的活动，可以只存信息、不占个人时间。

会议影响到学习计划时，先确认会议，再去看受影响的学习安排。系统不会为了让新活动有地方放，就偷偷把课程、考试或者你固定好的计划挪走。

## 8. 学习时间、计划和进度

在任务相关入口设每周能学习的时间段，一天可以设好几段，选星期的时候能一次批量选，然后合并或替换。临时排除的时间、每周的休息、安排前后的缓冲，都会参与计算。

要给哪个任务排时间，先补上预计还要多久、期限（如果有）、最早什么时候能开始、允不允许拆开、优先级。普通任务只要没写等待条件，就可以从这次允许的时段里开始排；明确写了“等审批”或者“某天之后才开始”的，这个条件会原样保留，不会被抹掉。

方案生成后先看一遍：排了哪些任务、占了哪些时段、哪些没排完。确认之后才是正式的学习安排。时间不够的时候它会老实显示还剩多少工作，而不是把任务时长改短来凑出一个“排完了”的结果。

安排好的某一段可以固定住，也可以取消、或者允许它被调整。之后要是又插进来一个固定活动，重新规划会保留固定段、保住每个任务的工作量，并且尽量少动其他地方。没被选中的任务照旧留着。首页那些空档建议，点了能进到相关安排，也能选“今天不推荐这个”。

学习进度是你自己记的：用了多久、还剩多少、做没做完。目前它不会根据你过去的实际耗时自动学出一个估时，也不会不经你确认就把没做完的自动滚到第二天。

任务的“时间评估”能看剩余工作、可用时段、同期其他任务一起占了多少、时间是怎么扣掉的。已有安排变了要刷新一下。它是按当前记录算的估算，不是对结果的保证。

## 9. 标签和分类

“学期 → 标签”里能搜标签，也能按分组看。已有的标签会自动整理，不额外弹合并提示；新建标签保存时用的也是整理后的统一名字。

整理规则大致这样：

- 组会、座谈会、班会、例会 → 会议
- 彩排、联排、排演 → 排练
- 分享会、学术讲座、报告会 → 讲座
- 实验报告、实验课作业、上机作业 → 实验作业
- 篮球、足球、羽毛球、健身、跑步 → 运动

该保留的区别还留着，比如 Python 和 Java、面试和笔试、排练和演出，不会一股脑合成一个。具体活动的叫法也还在事项标题和通知原文里。

系统会把标签分进课程与学习、科研与竞赛、会议与交流、文体活动、校园事务、求职与实习、生活日常这几组。不管是分类还是统一名字，都是程序规则算的，不调模型。

点标签名能看到关联的事项和日程，列表带时间、地点、完成或取消状态，其他学期的记录也在里面，点一条就进详情。右边的“更多”里保留手动重命名和合并，动手之前会先把影响摊给你看。标签跟着账号走，跨学期通用。

## 10. 搜索和统计

首页搜索能查课程、日程、任务、考试，还有通知的原文，可以按内容类型筛，结果能继续往下加载。点结果进详情。

“学期 → 统计”按日期范围、分类或标签看安排、占用、学习进度。这里有三个数别搞混：已排时长、去掉重叠之后的实际占用、以及你记的实际进度。只有开始时间没有结束时间的，不会被硬算成一段虚构的时长。

## 11. 本地提醒

在事项或日程详情里加提醒，按开始或截止时间提前；支持的事项还能指定一个具体时刻。记录被改、被完成、被取消之后会重新同步。

提醒最终交给 Android 系统调度，所以通知权限得给。没允许精确闹钟的情况下会退化成非精确调度，可能晚一点。静默时段只把声音和震动关掉，提醒本身的时间不变。

通知上的“10分钟后提醒”可以纯在本机完成，只要能读到本机账号、通知和缓存，断网也行，联网后再核对记录有没有变。“标记完成”动的是正式数据，必须服务端点头。

返回桌面、锁屏、上滑清掉最近任务，这几件事跟系统设置里的“强行停止”不是一回事。强行停止会连系统闹钟一起影响，得重新打开 App 再核对。各家厂商的电池管理也会影响送达。想排查的话，“桌面卡片与实时提醒”里有测试通知、本机清单，还能直接跳到系统的电池设置。

## 12. 桌面卡片、快速记录和进行中通知

在账户相关入口打开“桌面卡片与实时提醒”，可以把日程卡加到桌面。卡片显示的是本机已经同步下来的后续安排和同步状态，点一下能进详情或者快速记录。它用的是同步过的数据，替代不了网络上的即时更新。

临近 15 分钟或者正在进行的安排，可以手动开跟踪。知道结束时间就显示倒计时，不知道就显示已经开始多久。可以随时停，结束后自动撤下；结束时间未知的，最多留 12 小时。

Android 16 及以上会申请系统的增强展示，状态栏上到底显示不显示胶囊，取决于系统权限、资格和厂商。低版本用普通进行中通知。这些走的是系统接口，没有靠空转的后台服务去保进程。

## 13. 历史、撤销和来源

修改记录和回执都能核对改之前、改之后。允许撤销的操作，撤之前还会再看一眼当前状态；万一恢复旧内容会造出新的冲突，系统会说明原因，然后什么都不动。

来源详情里能看识别出的文字、原图或录音，可以重试识别、手改文字、删掉附件。删附件不会动已经存好的安排，核对要用的文字也留着。删一段对话会停掉它还没做完的处理，但已经确认过的业务记录保留。

删学期会先把关联数量列出来，确认之后这个学期的课程、日程、事项、计划、来源、对话一起删。有要留的东西，先导出。

## 14. 反馈、导出、退出和注销

“账户 → 反馈问题”里选个类别（识别、保存、提醒、界面、其他），写清楚你当时在做什么、实际发生了什么、期望是什么。反馈存在服务器上，开发者用维护工具看。现在没有应用内的工单进度，也不会自动回你。

“数据与隐私”能把个人记录导出成 JSON，存哪由你在系统文件选择器里定。导出的内容包括课程、安排、任务、计划、提醒、对话这些结构化数据，还有识别出的文字。原始图片和录音要从来源详情里单独管，导出里不含登录凭证。

退出登录会清掉登录态、本机账号缓存、学校登录信息、卡片和提醒；要是没清干净，按提示再点一次。注销要输密码，再打一句“删除我的账号”，然后删掉账户和关联数据，文件清理在后台继续跑。已经导出到自己文件夹里的文件，那就不归这个账号管了。

## 15. 网络和现在的边界

缓存能让你看已经同步下来的内容。助手、导入确认、保存、正式的任务完成、重排，这些都要连后端。暂时离线就先留着输入；碰到“预览过期”或者记录已经变了，刷新一下重新核对。

正式交付是 Android 客户端加服务端，学校适配器两所。更多学校、跨用户协作、按个人历史耗时学习估时、自动每日复盘，这些都还没做。深色模式的数值在设计代码里有，但 App 还没给切换开关。
