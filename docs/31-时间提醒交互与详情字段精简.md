# 时间、提醒与详情字段精简

日期：2026-09-27。针对用户给出的三个实际界面及“详情只显示已有属性”的反馈。

## 交互调整

- 日程、事项录入、考试改期统一为“暂定安排”开关。普通用户不再从“已确定/暂定/待确认”三个状态中辨别；历史 unknown 与 tentative 仍保存在底层，未操作开关时不改写原状态。
- 时间直接填写；日程结束时间按需添加或移除。常用日期/时刻在当前页面，周次、日期范围和不填写时间放在二级入口。不把未知结束时间补成一小时。
- 日程提醒改为条目列表，点条目编辑、独立删除、明确添加另一条；重复提前量去重。单条提醒的提前量使用单值输入，支持自定义分钟。
- 提醒用途和停用控制收进“更多设置”；选择14天不自动等同于开始复习，已有用途继续保留。日程的相对提醒不展示不支持的指定时刻/用途设置。

## 内容展示规则

- 日程没有结束、地点、提醒、来源时隐藏对应字段/分组。
- 事项没有截止、耗时、来源、提醒时不显示“待补充/没有原文”等占位。无耗时和关联复习任务时不突出更新进度，保留编辑、完成和按需添加提醒。
- 事项和日程详情中的日期/周次仅显示已知部分，不再在每行附带缺失说明。
- 课程详情收起空教师/地点/节次和空任务/考试分组；考试记录收起空地点，没有关联复习任务时不展示未设置目标占位。
- 已设置的提醒缺少触发所需时间时仍显示原因；已有计划、复习或实际风险的相关缺失提示保留。变更预览保留必要的前后对照，避免隐藏清空字段的影响。
